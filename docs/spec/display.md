# 表示

## 未確定文字列

場面は印の文字で表し、装飾はしない。どの印も設定で文字を決める。例では、読みを `›`、候補を `»`、送り仮名の始まりを `*`、登録を前後に半角スペースを付けた `«` としている（`›かんじ`、`»漢字`、`›か*く`、`»きしゃ « 記者`）。

印には次のものがある。

- 読み
- 候補
- 送り仮名の始まり
- 登録：読みと登録する文字列の間に置く
- カーソル：読みや登録する文字列の中のカーソルの位置
- 押さえたまま：[押さえたまま](keybindings.md#押さえたまま) に割り当てたキーが、押さえたままか単独で押したのか決まるまで出す

## モード

ABC モードとかなモードが切り替わったときだけ、モードを出せる環境では、カーソルの近くにモードを短く出す。カーソルの位置が分からないときは出さない。設定で出さないようにもできる。

## 候補

候補は、番号と表記の一覧でページに分けて出す。番号はページの中で振る。

- ページが 2 つ以上あるときは、出しているページと全体のページ数を示す。補完する読みの一覧でも同じ。
- 辞書から来た候補には、その辞書の名前を添える。
- OS の辞書で意味を引ける環境では、意味のある候補にそのことを示し、選んでいる候補の意味を一覧の横に出す。
- 補完する読みの一覧では、読みごとに、変換したとき最初に出る候補を添え、選んでいる読みのほかの候補も出す。
