# 表示

## 未確定文字列

場面は印の文字で表し、装飾はしない。どの印も設定で文字を決める。表の例では、読みを `›`、候補を `»`、送り仮名の始まりを `*`、登録を前後に半角スペースを付けた `«`、カーソルを `|`、押さえたままを `_` としている。

| 印 | 置き方 | 例 |
| --- | --- | --- |
| 読み | 読みの前 | `›かんじ` |
| 候補 | 候補の前 | `»漢字` |
| 送り仮名の始まり | その位置 | `›か*く` |
| 登録 | 読みと登録する文字列の間 | `»きしゃ « 記者` |
| カーソル | 読みや登録する文字列の中のカーソルの位置。末尾のときは出さない | `›かん\|じ` |
| 押さえたまま | [押さえたまま](keybindings.md#押さえたまま) に割り当てたキーが、押さえたままか単独で押したのか決まるまで、末尾。押さえたまま打って待っている文字を後ろに続ける | `›かん_j` |

- 登録の場面の入れ子は、外側から順に並べる。
- 押さえたままの印が空なら、見えない幅のない文字（U+200B）を置く。未確定文字列が空だと、アプリが押さえたキーを受け取ってしまうため。

## モード

「かな」「ABC」は、ABC モードとかなモードが切り替わったときだけ、カーソルの近くに短く出す。カーソルの位置が取れなければ出さない。設定で出さないようにもできる。

モードの表示には、ロゴの小さな記号を白で添え、地の色をモードごとに変える。

Linux（IBus）では、モードの表示も候補の一覧も IBus のパネルが描くので、その見た目になる。記号と地の色は付かない。ページの位置は、一覧の下ではなく補助テキストの先頭に `2 / 5` の形で出す。モードの表示は GNOME でだけ出す。

## 候補

候補は、番号と表記の一覧で出す。

- 一覧は 9 個ずつのページで出す。選んでいる候補のあるページを出し、番号はページの中で 1 から振る。
- ページが 2 つ以上あるときは、一覧の下に、出しているページと全体のページ数を `‹ 2 / 5 ›` の形で出す。補完する読みの一覧でも同じ。
- 候補が 1 つだけのときは、一覧を出さない。
- 辞書から来た候補には、その辞書の名前を表記の横に小さく添える。表記が同じ候補がいくつかの辞書にあるときは、[変換](conversion.md) で残した辞書の名前。名前は、ファイルの 1 行目に説明があればその説明、なければファイルの名前で、ユーザー辞書は「ユーザー辞書」。とても長い名前だけ、末尾を `…` にして縮める。読みを片仮名にしたものなど、辞書から来ていない候補には添えない。
- 出しているページの、辞書から来た候補の意味を OS の辞書で引く。意味が見つかった候補には、そのことを示す印を付ける。選んでいる候補に意味があれば、一覧の横に、候補と見分けのつく形で出す。引き終えるまでは印も意味も出さず、引けたところで出す。見つからなければ何も出さない。
- 補完する読みの一覧では、読みごとに、その読みを変換したとき最初に出る候補を添える（`かんじ` に「漢字」）。変換して候補が出ない読みには添えない。選んでいる読みには、2 番目からの候補も、変換したときの順に、一覧の横に 1 ページに入るぶんまで出す。辞書の名前と意味は添えない。
