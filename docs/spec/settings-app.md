# 設定アプリ

[設定ファイル](settings.md) と [設定のフォルダ](settings-folder.md) のファイルを、画面で変えるプログラム。IME とは通信しない。IME は、次に入力欄にフォーカスが入るとき、変わったファイルを読み直す。

## 設定ファイルを書く

- 変えた設定は、その場でファイルに書く。IME が読めない値は書かず、そのわけを示す。
- 割り当てを別のキーに移すときのように一度に変える設定は、すべて書くか、どれも書かないかのどちらか。1 つでも読めない値があれば、どれも書かない。
- 書くのは変えた設定の行だけで、ほかの行やコメントはそのまま残す。ひな形にある設定は、そのコメントを外した行にする。
- 既定値と違う設定には、既定値に戻す操作を、既定値を添えて出す。辞書の一覧は、利用者が並べたものなので出さない。戻すと、ひな形にある設定はひな形のコメントに戻し、ひな形にない設定は行を消す。
- 設定のファイルが TOML として読めなければ、変えずにそのわけを示す。
- 読めない設定があれば、その設定とわけを示す。

## 辞書

- dictionaries フォルダ（中のフォルダも含む）の辞書のファイル（`.tsv` と `.kdic`）と、組み込みの辞書を示す。組み込みの辞書には、組み込みであることを示す。並べ替えて、使うかどうかを選べる。テキストの辞書の 1 行目の説明と、読めない行とそのわけも示す。
- 辞書ごとに、語を読みの順に見られる。読みの始めで絞り込める。送り仮名のある語は、[テキストの辞書](text-dictionary.md) と同じく送り仮名の前に `*` を入れた読み（`か*く`）で引く。
- テキストの辞書は、[バイナリの辞書](binary-dictionary.md) に変換できる。同じ名前で拡張子が `.kdic` のファイルを作り、書いた一覧で使っていた元の辞書をそれに置き換える。
- テキストの辞書ごとに、変換していない・変換済み・再変換が必要のどれかを示す。変換済みは、今のテキストの辞書から作った、壊れていないバイナリの辞書があるとき。
- バイナリの辞書を一覧に足すときは、チェックサムを確かめる。合わなければ足さず、そのわけを示す。
- SKK の辞書を取り込める。[テキストの辞書に変換して](text-dictionary.md#skk-の辞書からの変換)、dictionaries フォルダに「元の名前.tsv」として置く。その名前のファイルがあれば残し、番号を付けた名前（「元の名前 2.tsv」）にする。
- ユーザーカスタム辞書で出さないとした（読み, 表記）を示し、戻せるようにする。戻すと、[その組の `!` の行を消す](text-dictionary.md#ユーザーカスタム辞書)。ユーザーカスタム辞書の語の行がその組を与えるときは、登録ごと消すこともできる。消すと、[その組を与える行と `!` の行を消す](text-dictionary.md#ユーザーカスタム辞書)。
- [よく選ぶ候補](conversion.md#よく選ぶ候補) の記録を消せる。消すと `selections.tsv` を消す。

### 公式の辞書

[kanaemi-dict](https://github.com/kanaemi-app/kanaemi-dict) が配る公式の辞書を、落として入れられる。

- 利用者が確かめる操作をしたときだけ、最新のリリースの目録（`index.json`）を取る。目録の形の版を読めなければ、そのわけを示す。
- 目録の辞書ごとに、説明と、入れていない・最新・新しい版があるのどれかを示す。最新は、入れた辞書のファイルが目録の SHA-256 と同じとき。基本辞書は、設定のフォルダの `ranking.model` も目録のモデルと同じとき。
- 入れていない辞書は入れられ、新しい版がある辞書は新しくできる。辞書の配布物を落とし、次のものがすべて合うときだけ入れる。合わなければ何も変えず、そのわけを示す。
  - 辞書のファイルと、基本辞書ではモデルのファイルが、目録の SHA-256 と同じ。
  - 基本辞書のモデルの形式の版が、[並べ替えのモデル](ranking-model.md#ファイル) の版と同じ。
- 入れるときは、配布物の辞書・`NOTICE`・`LICENSE` を、dictionaries フォルダの `kanaemi/<名前>/` に置き、辞書を [バイナリの辞書](binary-dictionary.md) に変換する。前の版のファイルは置き換える。基本辞書のモデルは、設定のフォルダの `ranking.model` を置き換える。
- 辞書の一覧には、変換したバイナリの辞書を足す。一覧にその辞書のテキストの辞書があれば、その位置で置き換える。なければ、基本辞書は一覧にある最初の公式の辞書の前に、追加辞書は最後に足す。どちらも、組み込みの辞書より前に置く。一覧を書いていなければ、それまで読んでいた辞書の一覧を書いてから足す。

## 関数

- functions フォルダの [関数](functions.md) と組み込みの関数を示し、それぞれ使うかどうかを選べる。組み込みの関数の代わりに使う functions フォルダの関数には、そう示す。
- functions フォルダの関数のうち、IME が使えないものは、そのわけを示す。関数を返さないファイル（モジュール）は示さない。
- 関数ごとに、中身（Luau のソース）を見られる。
- functions フォルダを開ける。

## キーバインド

- ふだんは、やりたいこと（読みを始める、変換する、確定する、モードを切り替えるなど）ごとにキーを決める。1 つのやりたいことに足したキーは、それが働く場面すべてに割り当て、外したキーは、どの場面からも外す。
- 一部の場面にだけ割り当ててあるキーは、その場面を添えて示す。
- アドバンスドでは、[キーバインド](keybindings.md) の場面ごとに割り当てを決める。
- キーは、名前を打つか、押して入れる。押し方（押したとき・単独押し・押さえたまま）は、そのキーに使えるものから選ぶ。
- 押さえたままの割り当てがあり、[キーを離したことを知るのに OS の許可が要る](keybindings.md#押さえたまま) 環境で、その許可がないときは、許可が要ることを示し、許可の設定を開けるようにする。
- 置き換えか `undo-commit` の割り当てがあり、[キーを送るのに OS の許可が要る](keybindings.md#ふだん) 環境で、その許可がないときも同じにする。
- どちらの見せ方でも、キーを置き換えないアプリを足したり外したりできる。アプリは、OS が示す名前とアイコンで示し、動いているアプリか、インストールしてあるアプリから選んで足す。OS がアプリを示せない環境では、名前を書いて足す。OS が知らないアプリは、書いてある名前で示す。

## そのほか

- ローマ字の表を選び、重ねる順を変えられる。用意された表には、組み込みであることを示す。表ごとに 1 行目の説明と、読めない行を示す。中身も見られる。
- IME のログの末尾を、新しい順に見られる。
