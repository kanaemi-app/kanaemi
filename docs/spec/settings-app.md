# 設定アプリ

[設定ファイル](settings.md) と [設定のフォルダ](settings-folder.md) のファイルを、画面で変えるプログラム。IME とは通信しない。IME は、次に入力欄にフォーカスが入るとき、変わったファイルを読み直す。

## 設定ファイルを書く

- 変えた設定は、その場でファイルに書く。IME が読めない値は書かず、そのわけを示す。
- 割り当てを別のキーに移すときのように一度に変える設定は、すべて書くか、どれも書かないかのどちらか。
- 書くのは変えた設定だけで、ほかの行やコメントはそのまま残す。
- 辞書の一覧のほかの、既定値と違う設定は、既定値に戻せる。
- 設定のファイルが TOML として読めなければ、変えずにそのわけを示す。
- 読めない設定があれば、その設定とわけを示す。

## 辞書

- dictionaries フォルダ（中のフォルダも含む）の辞書のファイルと、組み込みの辞書を示す。並べ替えて、使うかどうかを選べる。テキストの辞書の説明と、読めない行とそのわけも示す。
- 辞書ごとに、語を読みで探して見られる。
- テキストの辞書は、[バイナリの辞書](binary-dictionary.md) に変換でき、変換したものを元の辞書の代わりに使い、一覧でも元の辞書の代わりに示す。テキストの辞書ごとに、変換したものが今の中身に合っているかを示す。
- 壊れたバイナリの辞書は、一覧に足さず、そのわけを示す。
- [ほかの IME の辞書](other-ime-dictionaries.md) を、それぞれ別の辞書として取り込み、ユーザーカスタム辞書をそれらの形式に書き出せる。
- ユーザーカスタム辞書で出さないとした語を示し、また出すようにできる。その語を登録したのがユーザーカスタム辞書なら、登録ごと消すこともできる。どちらも [ユーザーカスタム辞書](text-dictionary.md#ユーザーカスタム辞書) のその語の行だけを変える。
- [よく選ぶ候補](conversion.md#よく選ぶ候補) の記録を消せる。

### 登録した語

ユーザーカスタム辞書の語を、一覧で見て、足し、直し、消せる。辞書ごとに語を見るところでユーザーカスタム辞書を開くと、この一覧を示す。

- 一覧に出すのは、ここで書ける形の語だけ。活用型やコストを書いた行のように、ここで書けない行は出さず、変えもしない。
- 語は、読みと表記で書く。書けるのは、IME の登録が書くのと同じ形の語。読みはひらがなで書き、数の入るところは数字ではなく置き場所で書く。送り仮名はかなで書く。置き場所の書き方は [表記の置き場所](placeholder.md#書き方) による。
- IME が読めない語は書かず、そのわけを示す。
- 足すと、ユーザーカスタム辞書にその語の行を足す。同じ語がもうあれば足さず、そう示す。出さないことにした語を足すと、IME の登録と同じく、また候補に出る。
- 直すと、その語の行をその場所で書き換える。元の語がもうないとき（手で書き換えたなど）や、直した語がほかにもうあるときは、何も変えず、そう示す。
- 消すと、その語の行を消す。
- 出さないとした行は、直しても消しても変えない。

### 公式の辞書

[kanaemi-dict](https://github.com/kanaemi-app/kanaemi-dict) が配る公式の辞書を、落として入れられる。

- 利用者が確かめる操作をしたときだけ、最新のリリースを調べる。
- 辞書ごとに、説明と、入れていない・最新・新しい版があるのどれかを示す。
- 入れていない辞書は入れられ、新しい版がある辞書は新しくできる。落としたものが配る側の示すものと合わないとき、またはこの版の Kanaemi が読めないときは、何も変えず、そのわけを示す。
- 入れた辞書は、dictionaries フォルダに置き、バイナリの辞書にして辞書の一覧に足す。辞書と一緒に配られる使用条件も置く。基本辞書は、その [並べ替えのモデル](ranking-model.md) も入れる。
- 新しくすると、前の版を置き換え、一覧での位置は変えない。

## 関数

- functions フォルダの [関数](functions.md) と組み込みの関数を示し、それぞれ使うかどうかを選べる。組み込みの関数の代わりに使う functions フォルダの関数には、そう示す。
- functions フォルダの関数のうち、IME が使えないものは、そのわけを示す。
- 関数ごとに、中身（Luau のソース）を見られる。
- functions フォルダを開ける。

## キーバインド

- ふだんは、やりたいこと（読みを始める、変換する、確定する、モードを切り替えるなど）ごとにキーを決める。1 つのやりたいことに足したキーは、それが働く場面すべてに割り当て、外したキーは、どの場面からも外す。
- 一部の場面にだけ割り当ててあるキーは、そう示す。
- アドバンスドでは、[キーバインド](keybindings.md) の場面ごとに割り当てを決める。
- [ふだん](keybindings.md#ふだん) の置き換えは、どの OS で動かしていても、OS ごとに何を送るかを並べて示し、変えられる。
- キーは、名前を打つか、押して入れる。押し方は、そのキーに使えるものから選ぶ。
- [キーを離したことを知る](keybindings.md#押さえたまま) か [キーを送る](keybindings.md#ふだん) のに OS の許可が要る割り当てがあり、その許可がないときは、許可が要ることを示し、許可の設定を開けるようにする。
- どちらの見せ方でも、キーを置き換えないアプリを足したり外したりできる。

## そのほか

- ローマ字の表を選び、重ねる順を変えられる。用意された表には、組み込みであることを示す。表ごとに説明と読めない行を示す。中身も見られる。
- IME のログの末尾を見られる。
