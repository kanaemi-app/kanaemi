# 設定ファイル

利用者の設定。[設定のフォルダ](settings-folder.md) の `config.toml`。IME と [設定アプリ](settings-app.md) が読み、手でも書ける。

- TOML。書ける設定は、IME が作るひな形にすべて書いてある。辞書の一覧を除き、ひな形に書いた値が既定値。
- ファイルがなければ、IME がひな形で作る。ひな形はすべての設定をコメントにしてあり、行頭の `#` を外した設定が効く。
- 書いていない設定は既定値。読めない設定は飛ばして既定値を使い、IME はログに残す。ファイル全体が TOML として読めなければ、すべて既定値を使う。
- [キーバインド](keybindings.md) の機能は `@` で始める（`@next`）。`@none` は割り当てを外す。[修飾キー](keybindings.md#修飾キー) の単独押しは、キーの名前の後に `#tap` を付ける（`left-shift#tap`）。[押さえたまま](keybindings.md#押さえたまま) は `#hold` を付ける（`space#hold`）。アプリに送るキーの置き換え（[ふだん](keybindings.md#ふだん)）には、機能ではなく送るキーの名前を書く。

## 辞書の一覧

- dictionaries フォルダの中のファイル名で書く。中のフォルダは `/` でつなぐ（`sub/a.tsv`）。先にあるものほど優先度が高い。
- `custom` はユーザーカスタム辞書の位置。書かなければ先頭に置く。
- 一覧を書かなければ、ユーザーカスタム辞書のあとに dictionaries フォルダ（中のフォルダも含む）の `.tsv` と `.kdic` を、`/` でつないだ名前の順に読む。同じ名前の `.kdic` がある `.tsv` は読まない。
- 一覧にある辞書のファイルが読めなければ、飛ばしてログに残す。

## ローマ字の表

- 用意された表の名前か、romaji フォルダの中のファイル名で書く。同じ名前なら、用意された表を使う。
- 書いた一覧が、既定の重ね方の代わりになる。後に書いた表が勝つ。読めない表は飛ばす。

## 未確定文字列の印

- [印](display.md#未確定文字列) は、空でない文字列で、改行とタブを含まない。
