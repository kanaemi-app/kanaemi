# テキストの辞書

人が書き、配り、やり取りするための辞書の形式。IME はこの形式のまま読める。利用者は、どのテキストの辞書も [バイナリの辞書](binary-dictionary.md) に変換して使える。

## ファイル

- UTF-8（BOM は無視する）。行末は LF。CR LF も受け付ける。UTF-8 として読めない行は無効。
- 空行と、`#` で始まる行は無視する。
- 1 行目が `#` で始まるなら、その行の残りはファイルの説明。
- それ以外の行は、タブで区切った項目行。

## 項目行

```
読み<TAB>表記
読み<TAB>表記<TAB>活用型
読み<TAB>表記<TAB>活用型<TAB>コスト
```

- 読みと表記は空にできない。活用型とコストは空でもよい。活用型が空なら活用しない語、コストが空ならコストを書かない行。
- コストは 0 から 4294967295 までの整数で、ASCII の数字だけで書く。それ以外のコストの行は無効。
- フィールドの数がこれ以外の行は無効。

### 語

```
きしゃ	記者
```

### 活用する語

読みと表記は語幹。活用型は [活用表](conjugation.md) の名前。

```
か	書	五段-カ行
```

知らない活用型の行は無効。

### 置き場所のある語

表記に [置き場所](placeholder.md) を書いた行。変換のたびに、置き場所を関数で埋める。読みに `{}` を含む行は数値の項目で、読みの `{}` は数の置き場所（[数値変換](numeric-conversion.md)）。

```
{}こ	{}個
{}がつ{}にち	{kanji}月{kanji}日
きょう	{-:date %Y-%m-%d}
```

[表記の置き場所](placeholder.md#書き方) で無効とする置き場所のある行、活用型のある行、送り仮名付きの行は無効。

### 送り仮名付きの語

読みの `*` で送り仮名の始まりを示す。`*` の後ろは、送り仮名の最初のかなか、そのかなの行の英字の 1 文字で、どちらも [バイナリの辞書の `OKURI` の表](binary-dictionary.md#okuri) にあるもの。

- かな（ひらがな）を書いた行は、そのかなを持つ語。表記はそのかなで終わる。送り仮名を指定して変換するとき、語幹（読み「か」、表記「書」）を、送り仮名の最初のかなが同じなら使う。
- 行の英字を書いた行は、行だけを持つ語。送り仮名の最初のかなが分からない語（[SKK の辞書からの変換](#skk-の辞書からの変換)）に使う。表記は語幹の表記だけを書く。送り仮名を指定して変換するとき、語幹を、送り仮名の最初のかながその行にあれば使う。

```
か*く	書く
か*k	書
```

`*` が 2 つ以上ある行、`*` の後ろがそのどちらでもない行、かなを書いて表記がそのかなで終わらない行、活用型のある行は無効。

### 出さない

ユーザーカスタム辞書（下）だけで使える。読みの先頭の `!` は、その（読み, 表記）をどの辞書の候補にも出さないことを表す。読みに `*` は書けず、送り仮名付きの候補は送り仮名を含めた読みと表記で書く。

```
!きしゃ	汽車
!かく	書く
```

## エスケープ

| 書き方 | 意味 | 使えるところ |
| --- | --- | --- |
| `\\` | `\` | すべてのフィールド |
| `\t` | タブ | すべてのフィールド |
| `\n` | 改行 | すべてのフィールド |
| `\#` | `#` | 読みの先頭 |
| `\!` | `!` | 読みの先頭 |
| `\*` | `*` | 読み |
| `\{` | `{` | 読みと表記 |
| `\}` | `}` | 表記 |

これ以外の `\` を含む行は無効。

## 読み方

- 読みと表記は NFC に正規化してから扱う。
- 無効な行は飛ばす。
- 同じ（読み, 表記, 活用型）の行が複数あれば、後の行が勝つ。`!` の行とそうでない行も同じ組として扱う。
- 送り仮名付きの語の行は、それより前の `!` の行のうち、その語を使う組を出さないものも打ち消す。その語を使う組は、送り仮名の前の読みと表記の両方に同じかなを続けた組で、続けたかなが、かなを持つ語ならそのかなで、行だけを持つ語ならその行のかなで始まるもの（`!かった	勝った` のあとの `か*っ	勝っ` や `か*t	勝`）。
- コストを書いた行は、そのコストを使う。
- コストを書かない行のコストは、同じ読み（送り仮名付きの語は、送り仮名の前の読みと `*` の後ろの文字）の項目のうち、後に書かれたものから数えた順番 0, 1, 2 …。数えるのは、無効な行と、同じ組の行のうち勝たなかった行と、`!` で消えた活用しない語を除いて残った項目。送り仮名付きの語は、`!` で出さなくしても数に入る。コストを書いた項目もこの数に入る。

## 書き出し

Kanaemi が書く行（辞書登録、[ほかの IME と SKK の辞書](other-ime-dictionaries.md) の取り込み）は、読むと書いたときの読み・表記・活用型・コストに戻る。

## SKK の辞書からの変換

SKK の辞書は、この形式に変換して使う。

- 送りなしの見出しは語の行に、送りありの見出しは行だけを持つ送り仮名付きの語の行に、`#` のある見出しは数値の項目の行にする。
- 見出しの中の候補の並びは、コストの列に残す。
- 候補の注釈と、この形式で表せない見出しと候補（S 式の候補など）は移さない。

## ユーザーカスタム辞書

辞書登録と削除を書き込むテキストの辞書。バイナリの辞書には書き込めないので、辞書の一覧には必ず 1 つある。[設定のフォルダ](settings-folder.md) の `custom.tsv`。

- 辞書登録と削除は、行を末尾に足す。すでにある行は書き換えない。
- [設定アプリ](settings-app.md#登録した語) で直した語と消した語は、その語の行だけを書き換える。
- 削除した語を戻すときと、登録ごと消すときは、その語を出さなくしている `!` の行を消す。登録ごと消すときは、その語を与える行も消す。
- 送り仮名を指定した読みで登録した語は、送り仮名付きの語の行で書く。送り仮名付きの語の行に書けない送り仮名なら、送り仮名を含めた読みで書く。
