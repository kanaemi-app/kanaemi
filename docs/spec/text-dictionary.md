# テキストの辞書

人が書き、配り、やり取りするための辞書の形式。IME はこの形式のまま読める。利用者は、どのテキストの辞書も [バイナリの辞書](binary-dictionary.md) に変換して使える。

## ファイル

- UTF-8（BOM は無視する）。行末は LF。CR LF も受け付ける。UTF-8 として読めない行は無効。
- 空行と、`#` で始まる行は無視する。
- 1 行目が `#` で始まるなら、その行の残りはファイルの説明。
- それ以外の行は、タブで区切った項目行。

## 項目行

```
読み<TAB>表記
読み<TAB>表記<TAB>活用型
読み<TAB>表記<TAB>活用型<TAB>コスト
```

- 読みと表記は空にできない。活用型とコストは空でもよい。活用型が空なら活用しない語、コストが空ならコストを書かない行。
- コストは 0 から 4294967295 までの整数で、ASCII の数字だけで書く。それ以外のコストの行は無効。
- フィールドの数がこれ以外の行は無効。

### 語

```
きしゃ	記者
```

### 活用する語

読みと表記は語幹。活用型は [活用表](conjugation.md) の名前。

```
か	書	五段-カ行
```

知らない活用型の行は無効。

### 置き場所のある語

表記に [置き場所](placeholder.md) を書いた行。変換のたびに、置き場所を関数で埋める。読みに `{}` を含む行は数値の項目で、読みの `{}` は数の置き場所（[数値変換](numeric-conversion.md)）。

```
{}こ	{}個
{}がつ{}にち	{kanji}月{kanji}日
きょう	{-:date %Y-%m-%d}
```

[表記の置き場所](placeholder.md#書き方) で無効とする置き場所のある行、活用型のある行、送り仮名付きの行は無効。

### 送り仮名付きの語

読みの `*` で送り仮名の始まりを示す。`*` の後ろは送り仮名の最初のかな 1 文字（ひらがなで、[バイナリの辞書の `OKURI` の表](binary-dictionary.md#okuri) にあるもの）で、表記はそのかなで終わる。送り仮名を指定して変換するとき、語幹（読み「か」、表記「書」）を、送り仮名の最初のかなが同じ行なら使う。

```
か*く	書く
```

`*` が 2 つ以上ある行、`*` の後ろがかな 1 文字でない行、表記がそのかなで終わらない行、活用型のある行は無効。

### 出さない

ユーザーカスタム辞書（下）だけで使える。読みの先頭の `!` は、その（読み, 表記）をどの辞書の候補にも出さないことを表す。読みに `*` は書けず、送り仮名付きの候補は送り仮名を含めた読みと表記で書く。

```
!きしゃ	汽車
!かく	書く
```

## エスケープ

| 書き方 | 意味 | 使えるところ |
| --- | --- | --- |
| `\\` | `\` | すべてのフィールド |
| `\t` | タブ | すべてのフィールド |
| `\n` | 改行 | すべてのフィールド |
| `\#` | `#` | 読みの先頭 |
| `\!` | `!` | 読みの先頭 |
| `\*` | `*` | 読み |
| `\{` | `{` | 読みと表記 |
| `\}` | `}` | 表記 |

これ以外の `\` を含む行は無効。

## 読み方

- 読みと表記は NFC に正規化してから扱う。
- 無効な行は飛ばす。
- 同じ（読み, 表記, 活用型）の行が複数あれば、後の行が勝つ。`!` の行とそうでない行も同じ組として扱う。
- 送り仮名付きの語の行は、それより前の `!` の行のうち、読みと表記の両方に同じかなを続けた組を出さないものも打ち消す（`!かった	勝った` のあとの `か*っ	勝っ`）。
- コストを書いた行は、そのコストを使う。
- コストを書かない行のコストは、同じ読み（送り仮名付きの語は、送り仮名の前の読みと送り仮名の最初のかな）の項目のうち、後に書かれたものから数えた順番 0, 1, 2 …。数えるのは、無効な行と、同じ組の行のうち勝たなかった行と、`!` で消えた活用しない語を除いて残った項目。送り仮名付きの語は、`!` で出さなくしても数に入る。コストを書いた項目もこの数に入る。

## 書き出し

Kanaemi が書く行（辞書登録、SKK の辞書の取り込み）は、読むと書いたときの読み・表記・活用型・コストに戻る。

## SKK の辞書からの変換

SKK の辞書は、この形式に変換して使う。

- 文字コードは、1 行目の `coding:` の指定に従う。指定がなければ EUC-JP として読む。
- 送りなしの見出しは、候補ごとに語の行にする。
- 見出しに `#` のあるものは、`#` を `{}` にして数値の項目の行にする。候補の `#0`・`#1`・`#2`・`#3`・`#5`・`#8` は `{}`・`{wide-num}`・`{kanji-num}`・`{kanji}`・`{daiji}`・`{grouped-num}` にし、そのほかの `#` と数字を含む候補は移さない。
- 送りありの見出し（`かk /書/`）は、候補ごとに送り仮名付きの語の行（`か*か	書か`）にする。送り仮名のかなは、見出しの英字の行の最初のかな（[バイナリの辞書の `OKURI` の表](binary-dictionary.md#okuri)）。表にない英字の見出しと、`x` の見出しは移さない（SKK の送りの英字は送り仮名の子音で、小さいかなの行はない）。
- コストの列には、見出しの中で移した候補の順番（0 から）を書く。
- 候補の `;` から後ろは移さない。
- S 式の候補（`(` で始まる）は移さない。
- U+FDD0・U+FDD1 を含む見出しと候補は移さない。項目は置き場所の `{`・`}` をこの文字で持つので、移すと置き場所として読まれる。

## ユーザーカスタム辞書

辞書登録と削除を書き込むテキストの辞書。バイナリの辞書には書き込めないので、辞書の一覧には必ず 1 つある。[設定のフォルダ](settings-folder.md) の `custom.tsv`。

- 辞書登録と削除は、行を末尾に足す。
- 削除した語を戻すときは、その（読み, 表記）の `!` の行をすべて消す。
- 削除した語を登録ごと消すときは、その（読み, 表記）の `!` の行と、その組を与える語の行をすべて消す。送り仮名付きの語の行は、組が、その行の送り仮名の前の読みと表記の両方に同じかなを続けたもので、そのかながその行の送り仮名と同じ行で始まるなら、その組を与える（`か*く	書く` は（かけ, 書け）を、`か*っ	勝っ` は（かった, 勝った）を与える）。
- Windows では、IME は書き込み用の別プロセスに行を送り、そのプロセスが書く（[Windows ではユーザーデータの書き込みを別プロセスに任せる](../adr/20261003-write-user-data-from-a-separate-process-on-windows.md)）。
- 送り仮名を指定した読みで登録した語は、送り仮名付きの語の行で書く（`;nu;nu` で登録した語は `ぬ*ぬ`。`begin` を `;` に割り当てたとき）。打ちかけの続きで送り仮名が伸びたとき（`;ka;tta` の「った」）は、送り仮名の始まりに打ったまとまりが送り仮名付きの語の行に書けるかななら、そのかなまでの読みと表記で書く（`か*っ	勝っ`）。送り仮名がそのどちらでも書けないとき（kya の きゃ、ー）は、送り仮名の印を付けずに、送り仮名を含めた読みで書く。
