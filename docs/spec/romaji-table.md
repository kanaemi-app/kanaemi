# ローマ字の表

かなモードで打った文字を何にするかを決める表の形式。用意された表も、利用者が書く表も、この形式のファイルにする（[ローマ字の表を重ねられるファイルにする](../adr/20261003-stack-romaji-tables-as-files.md)）。

## ファイル

- UTF-8（BOM は無視する）。行末は LF。CR LF も受け付ける。拡張子は `.tsv`。
- 空行と、`#` で始まる行は無視する。
- 1 行目が `#` で始まるなら、その行の残りはファイルの説明。
- それ以外の行は、タブで区切った規則行。

## 規則行

```
入力<TAB>出力
!入力
```

- 入力は、ASCII の印字可能な文字（`!` から `~` まで）で、空にできない。
- 出力は空にできない。
- `!` で始まる行は、その入力の規則を消す。
- フィールドの数がこれ以外の行は無効。

```
shi	し
z-	〜
!1
```

## エスケープ

| 書き方 | 意味 | 使えるところ |
| --- | --- | --- |
| `\\` | `\` | すべてのフィールド |
| `\#` | `#` | 入力の先頭 |
| `\!` | `!` | 入力の先頭 |

これ以外の `\` を含む行は無効。

## 重ね方

- 表は、空の表に、選んだファイルを順に当てはめて作る。ファイルの中では上の行から順に当てはめる。
- 同じ入力の規則は、後に当てはめたものが勝つ。消した入力も、後の行で足し直せる。
- 打った入力が、ある規則と一致し、別の規則の始まりにもなっているときは、続きを待つ。続きでどの規則にもならないときや、確定するときは、いちばん長く一致する規則を使い、残りは続けて当てはめる。
- 無効な行は飛ばす。

## 規則のほかの打ち方

打った入力がどの規則にもならないとき、次のように打てる。

- n に続けて打った文字で規則が作れなければ、n は ん（nka → んか）。確定のときに残った n も ん。
- 母音と n 以外の同じ英小文字を 2 つ続けると っ（kka → っか）。
- どの規則にもならない英小文字は捨てる。ただし、読みの外で確定するときに残った英小文字は、設定で打ったとおりに確定できる（`arew` のあと確定して「あれw」）。
- 表にない文字（英大文字を含む）は、打ったとおりに確定する。
