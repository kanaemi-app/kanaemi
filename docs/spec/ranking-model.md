# 並べ替えのモデル

[変換](conversion.md) の候補に点数を付ける線形モデル。辞書を作る側が学習し、IME は読むだけで学習し直さない。

## 点数

候補の点数は、その候補の特徴の重みの和。点数の大きい候補を先に並べる。特徴の作り方は Kanaemi が決め、学習する側も Kanaemi の作り方で特徴を作る。

## モデルが見るもの

候補ごとに、次のものから特徴を作る。これ以外は見ない。

- 読み（送り仮名を含む）と、候補の表記
- 候補が来た辞書の、一覧の中の位置
- 候補のコストと、語幹から組み立てた形かどうか
- この入力欄の確定履歴
- この入力欄で IME が確定した文字の末尾（変換した語も、かなのまま確定したものも）

確定した文字の末尾は、確定履歴と同じく、フォーカスが移ったら空にする。

## ファイル

[設定のフォルダ](settings-folder.md) の `ranking.model`。なければ、モデルなしで並べる。変わったら、[読み直す](settings-folder.md#読み直し)。整数はリトルエンディアン。

| 位置 | 大きさ | 中身 |
| --- | --- | --- |
| 0 | 8 | `KANAEMIM` |
| 8 | 4 | 形式の版（u32、`2`） |
| 12 | 1 | `bits`（重みの位置を表すビット数、10〜28） |
| 13 | 1 | 重みの型（`0` は f32、`1` は i8） |
| 14 | 2 | `0` |
| 16 | 4 | 尺度（f32。i8 の重みに掛ける。f32 の重みでは `1`） |
| 20 | 4 | `0` |
| 24 | 8 | 重みの XXH3-64 |
| 32 | — | 重みを `2^bits` 個 |

- 重みと尺度は有限の値。形式どおりでないファイルは使わない。重みの XXH3-64 は、読むときに確かめる。
- 特徴の作り方を変えたら、形式の版を上げる。別の版のモデルは使わない。
