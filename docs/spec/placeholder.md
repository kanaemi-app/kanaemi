# 表記の置き場所

辞書の項目の表記のうち、変換のたびに関数を呼んで埋める部分。読みの数を好きな書き方で書ける（[数値変換](numeric-conversion.md)）ほか、今日の日付のように、変換するたびに値の変わる語も書ける。

## 書き方

```
{位置:関数 引数}
```

- 位置：関数に渡す変換元を選ぶ。数字なら、読みの数を前から 0, 1, 2 … と数えたその番号の数。空なら次の数（位置を省いた置き場所だけで数える）。`-` なら読み全体。
- 関数：呼ぶ [関数](functions.md) の名前。名前が空なら、変換元をそのまま返す。名前に `:`・スペース・`{`・`}`・`\` は使えない。
- 引数：名前の後ろの最初のスペースより後ろ、`}` の前までの文字列。スペースがなければ、引数はない。`{`・`}`・`\` は `\{`・`\}`・`\\` と書く（[エスケープ](text-dictionary.md#エスケープ)）。
- `:` のない `{関数 引数}` は、`{:関数 引数}` と同じ。

| 書き方 | 意味 |
| --- | --- |
| `{}` | 次の数をそのまま書く |
| `{kanji}`・`{:kanji}` | 次の数を `kanji` で書く |
| `{1:kanji}` | 2 つ目の数を `kanji` で書く |
| `{1:}` | 2 つ目の数をそのまま書く |
| `{-:}` | 読み全体をそのまま書く |
| `{-:date %Y-%m-%d}` | `date` に、読み全体と `%Y-%m-%d` を渡す |

```
{}がつ{}にち	{-:date %Y}年{kanji}月{kanji}日
{}がつ{}にち	{-:date %Y}年{0:kanji}月{1:kanji}日
きょう	{-:date %Y-%m-%d}
```

読みには数の置き場所 `{}` だけを書き、位置・関数・引数は書かない。

次の置き場所のある行は無効。

- 位置の番号が、読みの `{}` の数以上。
- 位置を省いた置き場所が、読みの `{}` より多い。
- 位置が、数字・`-`・空のどれでもない。

## 埋め方

候補を作るとき、置き場所ごとに関数を呼び、その戻り値で置き場所を埋める。

- 関数には、変換元と引数を渡す。変換元は打ったままで、数字を半角にするなどの変換はしない。
- 関数が返した文字列は、NFC に正規化して使う。
- 関数がないとき、失敗したとき、文字列を返さなかったときは、その項目から候補を作らない。
- 送り仮名を指定して変換するときは、置き場所のある語から候補を作らない。

## 記録

置き場所のある項目から作った候補は、確定履歴・よく選ぶ候補・出さないことにした語に、置き場所のままの（読み, 表記）で入れる（`1こ` で 一個 を確定 → （`{}こ`, `{kanji}個`））。埋めた値が変わっても、同じ項目には同じ記録が効く。

## 辞書登録

登録する文字列に置き場所を含めると、置き場所のある項目として登録する。読みに数があれば、読みの数を `{}` にする（読み `１こ`、文字列 `{kanji}個` → `{}こ	{kanji}個`）。置き場所を含まない文字列や、置き場所として読むと無効な行になる文字列は、打ったままの読みと文字列で登録する。

置き場所のある項目として登録したときは、置き場所を埋めたものを確定する（読み `１こ`、文字列 `{kanji}個` → 一個）。
