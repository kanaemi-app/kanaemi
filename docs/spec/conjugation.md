# 活用表

活用する語の語幹の後ろに付いてよい読みを、活用型ごとに定める。表は 1 つで、すべての辞書が項目の活用型の名前で参照する。利用者は変えられない。

## 活用型の名前

UniDic の現代語の活用型の名前（五段-カ行、上一段-ア行、サ行変格、形容詞 など）を基にし、同じ型の中で語尾が違う語には Kanaemi 独自の型を足す（下の表）。

- 語幹は、どの形でも変わらない部分。一段活用では段のかなまで（食べ、見）、サ行変格では する の前まで（勉強）。
- 語幹の読みが形ごとに変わる語（カ行変格の 来る、単独の する、いい）は表で扱わず、それぞれの形を活用しない語として辞書に持つ。良い・良かった などは語幹「よ」の形容詞として持つ。
- 同じ型の他の語と語尾が違う語は、独自の型にする。

| 活用型 | 語の例 | 違う形 |
| --- | --- | --- |
| 五段-カ行-促音便 | 行く・逝く | 行った・行って |
| 五段-ワア行-ウ音便 | 問う・乞う・請う | 問うた・問うて |
| 五段-ラ行-特殊 | くださる・いらっしゃる・おっしゃる | いらっしゃい・いらっしゃいます |

## 語幹の後ろに付いてよい読み

活用型ごとに、活用形（音便を含む）の語尾と、その後ろに文法どおりに付く助動詞・助詞の連なりをつないだ短い読み（書か＋ない、書い＋た、食べ＋られる）。
