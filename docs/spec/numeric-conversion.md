# 数値変換

数を含む読みを、数の書き方を選べる候補に変換する（`１こ` → 1個・１個・一個）。辞書には数の代わりに置き場所を書いた項目（数値の項目）を置き、変換のときに打った数で埋める。

## 読みの中の数

数は、読みの中で続いている数字の並び。半角と全角の数字のどちらでもよい。一つの読みにいくつあってもよい（`1がつ2にち` の 1 と 2）。

読みは数字からも始められる（`begin` を `;` に割り当てたとき、`;1ko` → 読み「１こ」）。数字が全角になるかは [ローマ字の表](romaji-table.md) による。

## 数値の項目

[テキストの辞書](text-dictionary.md#置き場所のある語) の読みに `{}` を含む項目。読みの `{}` は数の置き場所で、前から順に読みの数が入る。表記の [置き場所](placeholder.md) で、その数をどう書くかを選ぶ。

```
{}こ	{}個
{}こ	{wide-num}個
{}こ	{kanji}個
{}がつ{}にち	{kanji}月{kanji}日
```

IME は、数の書き方として次の [組み込みの関数](functions.md#組み込みの関数) を持つ。どれも引数を使わず、変換元が数でなければ値を返さない。

| 名前 | 書き方 | 例（12） | 例（2026） |
| --- | --- | --- | --- |
| なし（`{}`） | 打ったまま | 12 | 2026 |
| `half-num` | 半角の数字 | 12 | 2026 |
| `wide-num` | 全角の数字 | １２ | ２０２６ |
| `kanji-num` | 漢数字を 1 けたずつ | 一二 | 二〇二六 |
| `kanji` | 位取りした漢数字 | 十二 | 二千二十六 |
| `daiji` | 位取りした大字 | 壱拾弐 | 弐千弐拾六 |
| `grouped-num` | 3 けたごとに `,` を入れた半角の数字 | 12 | 2,026 |

数値の項目は活用しない。活用型や送り仮名の始まりのある数値の項目は無効。

### 位取り

`kanji` は、万・億・兆・京の位で区切って書く（10000 → 一万）。書けないほど大きい数では、その候補は出さない。

### 大字

`daiji` は、`kanji` と同じく位取りし、一・二・三・十を壱・弐・参・拾にする。書けないほど大きい数では、その候補は出さない。

## 変換

- 読みに数があるとき、数を置き場所にした読みで、各辞書の数値の項目を引き（`１こ` → `{}こ`）、表記の置き場所を [埋めた](placeholder.md#埋め方) ものを候補にする。
- 数を置き換えない読みでも、ふつうどおり引く（`1ばん` という読みの項目があれば、それも候補）。
- 送り仮名を指定したときは、数値の項目を引かない。

数値の項目から作った候補の記録と、数値の項目の辞書登録は、[表記の置き場所](placeholder.md#記録) による。`1こ` で選んだ書き方は、`2こ` を変換したときも効く。
