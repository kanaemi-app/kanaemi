# 数値変換

数を含む読みを、数の書き方を選べる候補に変換する（`１こ` → 1個・１個・一個）。辞書には数の代わりに置き場所を書いた項目（数値の項目）を置き、変換のときに打った数で埋める。

## 読みの中の数

- 数は、読みの中で続いている数字の並び。数字は ASCII の `0`〜`9` と全角の `０`〜`９` で、混ざっていてもよい。
- 読みの中の数は、前から順に 1 つ目、2 つ目と数える（`1がつ2にち` の 1 と 2）。
- `,`・`.` などは数を区切る。`1.5` は 1 と 5 の 2 つの数。

読みは数字からも始められる（`begin` を `;` に割り当てたとき、`;1ko` → 読み「１こ」）。数字が全角になるかは [ローマ字の表](romaji-table.md) による。

## 数値の項目

[テキストの辞書](text-dictionary.md#置き場所のある語) の読みに `{}` を含む項目。読みの `{}` は数の置き場所で、表記の [置き場所](placeholder.md) で、その数をどう書くかを選ぶ。

```
{}こ	{}個
{}こ	{wide-num}個
{}こ	{kanji}個
{}がつ{}にち	{kanji}月{kanji}日
```

IME は、数の書き方として次の関数を持つ。どれも引数を使わない。

| 名前 | 書き方 | 例（12） | 例（2026） |
| --- | --- | --- | --- |
| なし（`{}`） | 打ったまま | 12 | 2026 |
| `wide-num` | 全角の数字 | １２ | ２０２６ |
| `kanji-num` | 漢数字を 1 けたずつ。0 は 〇 | 一二 | 二〇二六 |
| `kanji` | 位取りした漢数字 | 十二 | 二千二十六 |
| `daiji` | 位取りした大字 | 壱拾弐 | 弐千弐拾六 |
| `grouped-num` | 3 けたごとに `,` を入れた半角の数字 | 12 | 2,026 |

数値の項目は活用しない。活用型や送り仮名の始まりのある数値の項目は無効。

### 位取り

- 一・十・百・千のくりかえしに、万・億・兆・京を付ける（10000 → 一万、1000000 → 百万、100010 → 十万十）。
- 十・百・千の前の一は書かない（1111 → 千百十一）。万より上の一は書く（10000 → 一万）。
- 0 は 〇 にする。
- 京の 1 万倍以上の数は、`kanji` で書けない。その候補は出さない。

### 大字

- `kanji` と同じく位取りし、一・二・三・十を壱・弐・参・拾にする。ほかの字は変えない。
- 拾・百・千の前の壱も書く（1111 → 壱千壱百壱拾壱）。
- 京の 1 万倍以上の数は、`daiji` で書けない。その候補は出さない。

先頭の 0 は、`{}`・`wide-num`・`kanji-num` では打ったまま残し、`kanji`・`daiji`・`grouped-num` では落とす（`007` → 007・００７・〇〇七・七・七・7）。

## 変換

- 読みに数があるとき、各数を `{}` に置き換えた読みで、各辞書の数値の項目を引く（`１こ` → `{}こ`）。表記の置き場所を [埋めた](placeholder.md#埋め方) ものを候補にする。
- 数を置き換えない読みでも、ふつうどおり引く（`1ばん` という読みの項目があれば、それも候補）。
- 送り仮名を指定したときは、数値の項目を引かない。

どちらの候補も、そのあとは同じに扱う。まとめる・並べるときは、置き場所を埋めたあとの表記で比べる。

数値の項目から作った候補の記録と、数値の項目の辞書登録は、[表記の置き場所](placeholder.md#記録) による。`1こ` で選んだ書き方は、`2こ` を変換したときも効く。
