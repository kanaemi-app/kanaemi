# ほかの IME の辞書

ほかの IME の辞書を、それぞれ別の [テキストの辞書](text-dictionary.md) として取り込む。また、[ユーザーカスタム辞書](text-dictionary.md#ユーザーカスタム辞書) をそれらの IME の形式に書き出す。どちらも [設定アプリ](settings-app.md) が行う。

扱う IME は、MS-IME、Google 日本語入力、ATOK、macOS 標準と、SKK の各実装（macSKK、AquaSKK、ibus-skk、fcitx5-skk、fcitx5-cskk、CorvusSKK、DDSKK、skkeleton）。SKK の辞書は、どの実装のものでもない任意のファイルも扱う。どの IME の辞書かは、利用者が選ぶ。

## 取り込み

- 置き場所が決まっている辞書（SKK の実装のユーザー辞書、動いている macOS のユーザ辞書）は、ファイルを選ばせずにそれを読む。見つからなければ取り込めない。書き出しはできる。
- ほかは、利用者がファイルを選ぶ。
- 読んだあと、辞書を置く前に、取り込む語と、取り込まないものとそのわけを示す。利用者が取り込むと決めてから辞書を置き、やめれば何も書かない。
- 取り込まないのは、読めない行、Kanaemi で表せない語（Kanaemi で打てない読みの語など）、語を隠す指定（抑制単語）。取り込んだ辞書は語を隠せないため。
- 品詞は、Kanaemi の活用型に当たるものだけを使い、ほかは語として移す。
- 取り込んだ語は、dictionaries フォルダに、元の辞書にちなんだ名前の新しいテキストの辞書として置く。1 行目に、どこから取り込んだかを書く。すでにある辞書は書き換えない。
- ユーザーカスタム辞書は変えない。
- 文字コードを取り違えるおそれのあるファイル（読めないバイトがある）は、何も取り込まない。

## 書き出し

- ユーザーカスタム辞書の語を、選んだ IME がそのまま読み込める形で書き出す。SKK の実装へは、その実装が読む文字コードで書く。
- 書き出す IME で表せない語は書かず、その数を示す。
- 取り込んだ辞書の語は書き出さない。
