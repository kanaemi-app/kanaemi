# 変換

読みから候補を集めて並べる規則。辞書は [テキストの辞書](text-dictionary.md) か [バイナリの辞書](binary-dictionary.md) による。

## 候補を集める

各辞書から、次の候補を集める。

- 読みと一致する、活用しない語。
- 読みが「活用する語の語幹の読み＋その活用型で語幹の後ろに付いてよい読み（[活用表](conjugation.md)）」に分けられるとき、「語幹の表記＋後ろの読み」。このように組み立てた形は、そのまま一致する語より後ろに並びやすいよう、コストを上げて扱う。
- 送り仮名が指定されたときは、送り仮名付きの語から「表記＋送り仮名」。送り仮名の始まりに打ったまとまりで、読みは終わる。
- 読みに数があり、送り仮名が指定されていないときは、[数値の項目](numeric-conversion.md#変換) から作った候補。

集めた候補は次のように絞る。

- 送り仮名が指定されたときは、表記が送り仮名で終わる候補だけを残す。
- ユーザーカスタム辞書で出さないとされた（読み, 表記）を除く。
- 表記が同じ候補は 1 つにし、優先度の最も高い辞書のものを残す。辞書の一覧は、先にあるものほど優先度が高い。

## 並べる

[並べ替えのモデル](ranking-model.md) があれば、モデルの点数の大きい順に並べる。

モデルがなければ、次の順に並べる。

1. この入力欄で、同じ読みに対して最後に確定した表記
2. この入力欄の確定履歴にある表記
3. それ以外。辞書の優先度の順に並べ、同じ辞書の中はコストの小さい順に並べる

1・2 は辞書をまたいで先に出す。

どちらで並べたあとも、この入力欄でその読みをまだ確定していなければ、次の順に前へ出す。

1. 送り仮名が指定されたときは、送り仮名の始まりで分かれる候補（送り仮名付きの語から作った候補と、活用する語から組み立てた候補）を、ほかの候補より前へ出す。分かれる候補どうしの順は変えない。送り仮名の始まりは読みの区切りを表し、読みと一致する語（`;tachi;xya` の 立ちゃ）は、その区切りで分かれる語とは限らない。
2. [よく選ぶ候補](#よく選ぶ候補) を先頭へ出す。

同じ読み・送り仮名・辞書の一覧・モデル・確定履歴・よく選ぶ候補・直前の文字なら、並びはいつも同じ。

## 確定履歴

- 入力欄ごとに、確定した（読み, 表記）を直近 300 語ぶん持つ。
- 数値の項目から作った候補は、置き場所のままの（読み, 表記）で持つ。よく選ぶ候補の記録も同じ。
- フォーカスが移ったら捨てる。
- パスワード欄では持たない。

## よく選ぶ候補

入力欄やセッションをまたいで、何度も選んだ候補を先に出す。1 度選んだだけでは順は変わらない。古い選択ほど軽くする。

- 記録は [設定のフォルダ](settings-folder.md) の `selections.tsv` に置く。消されていれば、記録は空から始める。
- 記録には読みと表記を残し、いつ選んだかは残さない。持ち主だけが読み書きできるファイルにする。
- パスワード欄では記録しない。

## 辞書がないとき

読めない辞書は飛ばす。候補がなければ空を返す。
