# 変換

読みから候補を集めて並べる。辞書は [テキストの辞書](text-dictionary.md) か [バイナリの辞書](binary-dictionary.md) による。

## 候補を集める

各辞書から、次の候補を集める。

- 読みと一致する、活用しない語。
- 読みが「活用する語の語幹の読み＋その活用型で語幹の後ろに付いてよい読み（[活用表](conjugation.md)）」に分けられるとき、「語幹の表記＋後ろの読み」。
- 送り仮名が指定されたときは、送り仮名付きの語から「表記＋送り仮名」。送り仮名は、送り仮名の始まりに打ったまとまりと、その打ちかけの続きで仕上がったかな（[送り仮名](input-method.md#送り仮名)）。
- 読みに数があり、送り仮名が指定されていないときは、[数値の項目](numeric-conversion.md#変換) から作った候補。

集めた候補は次のように絞る。

- 送り仮名が指定されたときは、表記が送り仮名で終わる候補だけを残す。
- ユーザーカスタム辞書で出さないとされた（読み, 表記）を除く。
- 表記が同じ候補は 1 つにし、優先度の最も高い辞書のものを残す。辞書の一覧は、先にあるものほど優先度が高い。

## 並べる

[並べ替えのモデル](ranking-model.md) があれば、モデルの点数で並べる。モデルがなければ、辞書の優先度とコストで並べ、この入力欄で確定した表記を先に出す。

どちらで並べたあとも、この入力欄でその読みをまだ確定していなければ、何度も選んだ候補（[よく選ぶ候補](#よく選ぶ候補)）を先に出す。

同じ読み・送り仮名・辞書の一覧・モデル・確定履歴・よく選ぶ候補・直前の文字なら、並びはいつも同じ。

## 補完

[補完](input-method.md#補完) では、打った読みで始まり、それより長い読みを出す（`かく` から `かくにん`）。送り仮名の始まりを付けた読みは補完しない。

- 出すのは、この入力欄で確定した読み、何度も選んだ候補の読み、辞書の活用しない語の読み。
- 確定した読みと何度も選んだ読みを、辞書の読みより先に出す。
- 同じ読み・辞書の一覧・確定履歴・よく選ぶ候補なら、並びはいつも同じ。

## 確定履歴

- 入力欄ごとに、最近確定した（読み, 表記）を持つ。
- フォーカスが移ったら捨てる。
- パスワード欄と、[記録しないよう求める入力欄](#記録しないよう求める入力欄) では持たない。
- かなのない読み（`pdf`）で確定した候補は持たない。よく選ぶ候補にも記録しない。

## よく選ぶ候補

入力欄やセッションをまたいで、何度も選んだ候補を先に出す。1 度選んだだけでは順は変わらない。古い選択ほど軽くする。

- 記録は [設定のフォルダ](settings-folder.md) に置く。消されていれば、記録は空から始める。
- 記録には読みと表記を残し、いつ選んだかは残さない。持ち主だけが読み書きできるファイルにする。
- パスワード欄と、[記録しないよう求める入力欄](#記録しないよう求める入力欄) では記録しない。

## 記録しないよう求める入力欄

ブラウザのプライベートウィンドウなど、入力したものを残さないよう求める入力欄では、確定履歴を持たず、よく選ぶ候補も記録しない。登録した語は辞書に入る。

入力欄がそう求めていることは、OS が入力欄について伝えることから見分ける。OS が伝えないときは見分けない。

## 辞書がないとき

読めない辞書は飛ばす。候補がなければ空を返す。
