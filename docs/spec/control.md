# 外からの操作

エディタなどのほかのプログラムが、動いている IME のモードを知り、変え、変わったことを知る。対象は、そのときフォーカスのある入力欄。

## つなぐ

- IME は、[設定ファイル](settings.md#外からの操作) にポートが書いてあるときだけ、`127.0.0.1` のそのポートで TCP の接続を待つ。
- そのポートで待てないとき（ほかのプログラムが使っているなど）は、ログに残し、待たずに動き続ける。
- 接続に、相手を確かめる手順はない。同じマシンのプログラムなら、どれでもつなげる。

## やりとり

- 1 行に 1 つの JSON のオブジェクトを、UTF-8 で送りあう。行末は LF。
- JSON のオブジェクトとして読めない行が来たら、答えずに切る。HTTP などほかの手順で話しかけられても、何もしない。
- 1 つの接続で、要求をいくつでも送れる。要求に `id` を付けると、答えに同じ `id` が付く。`id` は数か文字列。

### 要求

| 要求 | 答え |
| --- | --- |
| `{"op": "get-mode"}` | 今のモード（`{"mode": "kana"}`） |
| `{"op": "set-mode", "mode": "abc"}` | モードを変え、変えたあとのモードを答える |
| `{"op": "watch-mode"}` | 今のモードを答え、以後、モードが変わるたびに知らせる |

モードの名前は `kana` か `abc`。

### モードを変える

- 今と同じモードにするときは、何もしない。何度送っても結果は同じ。
- `abc` にすると、打っている途中のものは [`abc` の機能](keybindings.md) と同じに扱う（読みや選んでいる候補は確定する）。
- パスワードの入力欄は `abc` のまま変わらない。`kana` にしようとしても、答えは `abc`。
- 変えても、[モードの表示](display.md#モード) は出さない。
- 入力欄のあるアプリが応答しないときは、変わるのを長くは待たず、そのとき分かっているモードを答える。そのアプリは、あとで応答しても、そのモードに変えない。

### 知らせ

`watch-mode` を送った接続には、フォーカスのある入力欄のモードが変わるたびに知らせを送る。利用者が切り替えたとき、外から変えたとき、フォーカスがほかの入力欄に移ったときのどれでも送る。

```json
{"event": "mode", "mode": "abc"}
```

- Kanaemi を使っている入力欄からフォーカスが外れたときは、`"mode": null` を送る。
- `watch-mode` を送ったときにフォーカスのある入力欄がなければ、`{"mode": null}` と答える。
- 知らせは、接続が切れるまで続く。

### うまくいかないとき

答えの代わりに、`error` にわけを入れて返す。接続は切らない。

```json
{"id": 3, "error": "no-field", "message": "…"}
```

| `error` | わけ |
| --- | --- |
| `no-field` | Kanaemi を使っている入力欄にフォーカスがない |
| `bad-request` | `op` を知らない、`mode` の名前を知らない |

`message` は人が読むための説明で、書き方は決めない。

## 例

設定ファイルにポートを書いた Vim で、挿入モードを抜けたら ABC モードにする（ポートが 50123 のとき）。

```vim
let s:ch = ch_open('127.0.0.1:50123', {'mode': 'nl'})
autocmd InsertLeave * call ch_sendraw(s:ch, json_encode({'op': 'set-mode', 'mode': 'abc'}) .. "\n")
```
