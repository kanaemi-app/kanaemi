# コンセプト

Kanaemi が何を目指し、どんな考えで設計を判断するかを書く。

## Kanaemi とは

OS によらず同じように使えることを目指す日本語入力（IME）。読みの区切りを自分で決めて 1 語ずつ確定する [SKK](http://openlab.jp/skk/) の打ち方を土台に、次のことを変える。

- 活用した語も、送り仮名の始まりを示さずに読みのまま変換できる。
- 候補を、文脈に合わせて並べる。

名前は「かな（kana）」と「笑み（emi）」から。emi を逆から読むと ime になる。

## 誰のためのものか

- 複数の OS を行き来し、どこでも同じ操作で日本語を打ちたい人
- SKK のように、区切りを自分で決めて 1 語ずつ確定する打ち方をしたい人

## 原則

### どの OS でも同じ

キーの意味も、変換の結果も、OS によらず同じにする。

### 覚えることを少なく

利用者が切り替えるモードは、かなモードと ABC モードだけ。読みを打つ、候補を選ぶ、語を登録するといった状態には、打ち方の流れで入り、流れで抜ける。SKK のカタカナモードや全英モードは持たず、カタカナや英数は確定するときに選ぶ。

### 設定なしで使える

必須の設定は増やさない。既定値は作者が使いやすいと考える形にはっきり決め、そのままで使えるようにする。違う使い方をしたい人のために、変えられるところは変えられるようにする。

### 利用者が指示したときだけ変換する

打ったそばから画面が変わるライブ変換や、打つたびに出る予測候補は持たない。

### 入力の流れを止めずに辞書を育てる

候補がなければ、その場で語を登録して確定まで進める。

### 入力を外に出さない

IME はパスワード以外のすべての入力を見る。変換は手元で完結させ、入力を外へ送らない。

### 止まらない

IME が止まると、文字を打てなくなる。何が起きても、文字を打てる状態を保つ。
