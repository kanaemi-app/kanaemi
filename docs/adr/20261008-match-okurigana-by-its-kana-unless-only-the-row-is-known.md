# 送り仮名付きの語は送り仮名の最初のかなで引き、行しか分からない語だけを行で引く

状態：採用

## 背景

送り仮名を指定して変換するとき、送り仮名付きの語は、語幹と、送り仮名の最初のかなの行で引いていた。SKK の辞書の送りありの見出しは送り仮名の子音しか持たない（`きt /切/着/`）ので、行で引くしかない。テキストの辞書に取り込むときは、行の最初のかなを代わりに書いていた（`か*か	書か`）。行で引けば、その 書 が 書く・書け にも使える。

一方、文章から作る辞書は、使われた形ごとに本当のかなを持つ（`き*っ	切っ`、`き*た	着た`、`き*て	来て`）。これを行で引くと、た行の っ・た・て が混ざり、`;ki;tta` に 着った・来った が出る。辞書の行はどれも正しい語なのに、引き方が誤った候補を作る。テキストの辞書の行は代わりのかなと本当のかなを見分けられないので、どちらも行で引くしかなかった。

## 決定

- 送り仮名付きの語を、送り仮名の最初のかなを持つ語と、その行だけを持つ語に分ける。
- かなを持つ語は、指定した送り仮名の最初のかなが同じときだけ使う。行だけを持つ語は、今までどおり、同じ行なら使う。
- テキストの辞書では、`*` の後ろにかなを書いた行をかなを持つ語、行の英字を書いた行を行だけを持つ語にする（`か*k	書`）。英字は、バイナリの辞書の送り仮名の索引が行を表すものと同じにする。
- SKK の辞書の送りありの見出しは、代わりのかなを書かず、行だけを持つ語として取り込む。
- 辞書登録は、打った送り仮名の最初のかなを持つ語として書く。
- バイナリの辞書の送り仮名の索引は、キーの末尾を、かなを持つ語ならそのかな、行だけを持つ語なら行の英字にする。形式の版は上げない。前からあるファイルのキーの末尾はすべて英字なので、その語は行だけを持つ語として今までどおり引ける。

## 検討した他の案

- 行で引いたまま、紛らわしい行を辞書から除く：行の誤りではなく引き方の誤りで、除けば 着た・来て という正しい語まで消える。
- 行だけを持つ語に印を付けず、取り込みでも代わりのかなを書き続ける：代わりのかなと本当のかなを見分けられず、取り込んだ 書 は 書か にしか使えなくなるか、本当のかなの行も行で引くままになる。
- 行で引く方を印のない書き方のままにし、かなを持つ語に印を付ける：前からあるテキストの辞書は今までどおり動くが、配っている辞書と、登録で書いた行のすべてに印が要り、印を付けるまで誤った候補は出続ける。書いたかなを書いたとおりに使わない方が、印のない書き方の意味になる。
- バイナリの辞書の形式の版を上げる：前からあるファイルが読めなくなる。行だけを持つ語として読めば今までどおり引けるので、上げなくてよい。
- 前からあるバイナリの辞書の語を、かなを持つ語として読む：そのファイルは行の英字しか持たず、送り仮名の最初のかなが残っていない。
- かなを持つ語の索引を、別のセクションにする：形が同じ索引が 2 つになるだけで、キーの末尾がかなか英字かで見分けられる。
- 辞書登録で、行だけを持つ語として書く：同じ行のほかの形（勝っ から 勝つ）にも出るが、打ったかなを捨て、文章から作る辞書で起きた誤り（着た から 着った）を、利用者の登録でも作る。

## 結果

- 文章から作る辞書の送り仮名付きの語は、送り仮名の最初のかなが違う形には出ない。ほかの形は、その形の行か、活用する語から組み立てた候補で出る。
- 登録した送り仮名付きの語は、登録したときと同じかなで始まる送り仮名にだけ出る（`か*っ	勝っ` は 勝った・勝って に出て、勝つ には出ない）。前に登録した行も同じ。
- 前に取り込んだ SKK の辞書は代わりのかなを書いているので、取り込み直すまでは、そのかなで始まる送り仮名にだけ出る。
- 行だけを持つ語の行は、前の版の IME では無効な行として飛ばされる。かなを持つ語を入れたバイナリの辞書を前の版の IME で読むと、その語は引けない。
