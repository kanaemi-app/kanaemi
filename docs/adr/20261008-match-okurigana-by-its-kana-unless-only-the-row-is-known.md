# 送り仮名付きの語は送り仮名の最初のかなで引き、行しか分からない語だけを行で引く

状態：採用

## 背景

送り仮名付きの語を、語幹と、送り仮名の最初のかなの行で引いていた。SKK の辞書の送りありの見出しは送り仮名の子音しか持たないので、行で引くしかない。行で引けば、1 つの語が同じ行のほかの形にも使える（書か の 書 が 書く・書け にも使える）。

一方、文章から作る辞書は、使われた形ごとに本当のかなを持つ（切っ、着た、来て）。これを行で引くと、た行の っ・た・て が混ざり、きった に 着った・来った が出る。辞書の語はどれも正しいのに、引き方が誤った候補を作っていた。テキストの辞書は、SKK の辞書から取り込んだ代わりのかなと本当のかなを見分けられないので、どちらも行で引くしかなかった。

## 決定

- 送り仮名付きの語を、送り仮名の最初のかなを持つ語と、その行だけを持つ語に分ける。
- かなを持つ語は、打った送り仮名の最初のかなが同じときだけ使う。行だけを持つ語は、今までどおり同じ行なら使う。
- 辞書にかなが書いてあれば、そのかなを持つ語とする。行だけを持つ語は、行だけであることを示して書く。
- SKK の辞書の送りありの見出しは、行だけを持つ語として取り込む。
- 辞書登録は、打った送り仮名の最初のかなを持つ語として書く。

## 検討した他の案

- 行で引いたまま、紛らわしい語を辞書から除く：誤っているのは辞書でなく引き方で、除けば 着た・来て という正しい語まで消える。
- 行だけを持つ語を示さず、取り込みでも代わりのかなを書き続ける：代わりのかなと本当のかなを見分けられず、どちらも行で引くままになる。
- かなを持つ語の方を示して書き、示さない語は行で引く：前からある辞書は今までどおり動くが、配っている辞書と登録した語のすべてに印が要り、印を付けるまで誤った候補は出続ける。書いたかなを書いたとおりに使わないことになる。
- 辞書登録で、行だけを持つ語として書く：同じ行のほかの形にも出るが、打ったかなを捨て、文章から作る辞書で起きた誤りを、利用者の登録でも作る。

## 結果

- 文章から作る辞書の送り仮名付きの語は、送り仮名の最初のかなが違う形には出ない。ほかの形は、その形の語か、活用する語から組み立てた候補で出る。
- 登録した送り仮名付きの語は、登録したときと同じかなで始まる送り仮名にだけ出る（勝っ は 勝った・勝って に出て、勝つ には出ない）。前に登録した語も同じ。
- 前に取り込んだ SKK の辞書は代わりのかなを書いているので、取り込み直すまでは、そのかなで始まる送り仮名にだけ出る。
- 行だけを持つ語は、前の版の IME では読めない。
