# 送り仮名が伸びたら変換し直す

状態：採用（`20261003-convert-when-the-user-marks-the-boundary.md` のうち、送り仮名の最初のかなの後ろに打った文字の扱いを置き換える）

## 背景

送り仮名を指定すると、送り仮名の最初のかなを打った時点で変換する。最初のかなが打ちかけを残すことがある（`;ka;tt` の「っ」と打ちかけ `t`）。打ちかけを仕上げたかな（`a` で「た」）は候補の後ろに足して見せるだけで、候補は「勝っ」のまま変わらなかった。未確定の文字列は「勝った」なのに、候補の一覧は「勝っ」と出る。仕上がったかなは、候補を絞ることにも、並べることにも使われない。

## 決定

- 送り仮名の最初のかなを打った時点で変換するのは変えない。
- 候補を選んでいる間に打ちかけが仕上がったら、仕上がったかなまでを送り仮名にして変換し直す（`;ka;tta` は送り仮名「った」で変換する）。
- 送り仮名が伸びても、送り仮名付きの語として覚えるのは、送り仮名の最初のかなまでにする。

## 検討した他の案

- 仕上がったかなを、候補の一覧の各候補の後ろに足して見せるだけにする：見た目は揃うが、活用で絞ることにも、伸びた送り仮名で学んだ並びにも使えない。
- 送り仮名の最初のかなを打っても、打ちかけが仕上がるまで変換を待つ：打ちかけを残すかなは、続きを打たずに確定することもある（`;mo;tt` のあと別の語を打つ）。そのときに候補が出ていない。
- 伸びた送り仮名ごと、送り仮名付きの語として覚える：送り仮名付きの語は、送り仮名の最初のかなの行で引く。「勝った」として覚えると、「勝つ」「勝って」で引けない。

## 結果

- 候補を選んでいる間に、候補が入れ替わることがある。選んでいた候補は、仕上がったかなを足した表記が候補にあれば、選んだままにする。
- 送り仮名を、最初のかなとその後ろに分けて扱う必要がある。
