# macOS では候補の一覧を IME が自分で描く

状態：採用

## 背景

macOS では、候補の一覧を Input Method Kit の候補パネルに描かせていた。パネルに渡せるのは候補の文字列だけで、文字列に付けた色や大きさは無視される。

候補の一覧には、表記のほかに、その候補がどの辞書から来たかと、選んでいる候補の意味を添えたい。同じ読みの語を選び分ける手がかりになるためで、どちらも表記と見分けのつく形で出す必要がある。

## 決定

- macOS では、候補の一覧を IME が自分の窓に描き、Input Method Kit の候補パネルは使わない。

## 検討した他の案

- Input Method Kit の候補パネルを使い続ける：表記と別の形で添えられるものがない。候補の文字列に辞書の名前や意味を書き足すと、表記と見分けにくく、一覧の幅も読みにくくなる。

## 結果

- 窓の置き場所、明るい外観と暗い外観、クリックでの選択、アプリからフォーカスを奪わないことを、IME が自分で受け持つ。
- macOS の新しい版で候補パネルの見た目や振る舞いが変わっても、一覧はそれに付いていかない。
