# macOS では候補の一覧を IME が自分で描く

状態：採用

## 背景

候補の一覧に、表記と見分けのつく形で、表記のほかのことを添えたい。macOS では一覧を Input Method Kit の候補パネルに描かせていたが、パネルに渡せるのは候補の文字列だけで、形を変えて添えることができない。

## 決定

macOS では、候補の一覧を IME が自分の窓に描き、Input Method Kit の候補パネルは使わない。

## 検討した他の案

- 候補パネルを使い続け、添えるものを候補の文字列に書き足す。表記と見分けがつかず、確定する文字列と表示する文字列も分けて持つことになる。

## 結果

- 窓の置き場所、外観、クリックでの選択、アプリからフォーカスを奪わないことを、IME が受け持つ。
- macOS の新しい版で候補パネルが変わっても、一覧はそれに付いていかない。
