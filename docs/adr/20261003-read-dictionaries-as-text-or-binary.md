# 辞書はテキストでもバイナリでも読む

状態：採用

## 背景

辞書は人が書いて配れる形がよい。一方、大きな辞書は、使う前に全体を解析すると時間とメモリがかかる。

## 決定

- IME は、人が書けるテキストの辞書も、解析せずにそのまま引けるバイナリの辞書も読む。
- テキストからバイナリへの変換は、利用者が必要なときに行う。
- バイナリの辞書には書き込めないので、書き込み用のテキストの辞書（ユーザーカスタム辞書）を必ず 1 つ持つ。
- 形式は拡張子ではなく、ファイルの先頭で見分ける。
- バイナリの辞書は、変換元のテキストを見分ける値を持てる。元のテキストを直したあとで、変換し直す必要があるかを見分けるため。
- バイナリの辞書の全体のチェックサムは、一覧に足すときに設定アプリが確かめる。IME は開くたびには確かめず、形が正しいかだけを見る。

## 検討した他の案

- テキストだけにする：大きな辞書で、開くたびに解析の時間とメモリがかかる。
- 一覧に足すときに必ずバイナリにする：手元で直しながら使うテキストの辞書まで、直すたびに変換が要る。
- IME が開くたびに全体のチェックサムを確かめる：大きな辞書で、開くのが遅くなる。

## 結果

- バイナリの辞書は、それを読むプロセスの間で共有できる。
- 設定アプリを通さずに一覧に入ったバイナリの辞書は、全体のチェックサムを確かめないまま使う。
