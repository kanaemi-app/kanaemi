# 辞書は、人が書けるテキストでも、解析せずに引けるバイナリでも読む

状態：採用

## 背景

辞書は、人が書いて配れる形がよい。一方、大きな辞書は、使う前に全体を解析すると時間とメモリがかかる。

## 決定

- IME は、人が書けるテキストの辞書も、解析せずにそのまま引けるバイナリの辞書も読む。どちらも同じ辞書の一覧に並べられる。
- テキストからバイナリへの変換は、利用者が必要なときに行う。

## 検討した他の案

- テキストだけにする：大きな辞書で、開くたびに解析の時間とメモリがかかる。
- バイナリだけにする：人が書いた辞書を、使う前に必ず変換する必要がある。
- 一覧に足すときに必ずバイナリにする：手元で直しながら使うテキストの辞書まで、直すたびに変換が要る。

## 結果

- バイナリの辞書には書き込めないので、書き込む辞書（ユーザーカスタム辞書）はテキストになる。
- バイナリの辞書は、それを読むプロセスの間で共有できる。
- 元のテキストを直したら、バイナリの辞書を変換し直す必要がある。
