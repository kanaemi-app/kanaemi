# ユーザーカスタム辞書を、人が編集できる追記型のテキストにする

状態：採用

## 背景

ユーザーカスタム辞書には、辞書登録した語と、出さないことにした候補が入る。IME と設定アプリが書くだけでなく、利用者が自分で読み、まとめて直せる必要がある。同期フォルダに置いて、複数の端末で使うこともある。

## 決定

- ユーザーカスタム辞書は、人が読み書きできるテキストのファイル 1 つにする。
- IME は書き足すだけで、すでにある内容を書き換えない。後に書いたものが前に書いたものに勝つ。

## 検討した他の案

- 端末ごとの追記ログ：同期フォルダでの衝突は避けられるが、人が読んで直すには向かない。
- 端末ごとのテキストファイル：ある端末の登録と別の端末の削除のどちらが勝つかを、時刻なしには決められない。
- SKK の個人辞書の形式：送りありと送りなしで見出しの形が違い、候補を 1 つの見出しにまとめるので、足すたびに既存の内容を書き換える必要がある。
- バイナリの辞書：手で編集できない。

## 結果

- 同期フォルダに置くと、別の端末で同時に書いたときの衝突は同期の仕組みに任せることになる。
- 書いた内容を取り消すには既存の内容を消す必要があるので、IME ではなく設定アプリが行う。
