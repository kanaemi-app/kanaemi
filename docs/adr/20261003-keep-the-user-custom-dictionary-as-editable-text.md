# ユーザーカスタム辞書を手で編集できるテキストにする

状態：採用

## 背景

ユーザーカスタム辞書には、辞書登録した語と、出さないことにした候補が入る。IME と設定アプリが書くだけでなく、利用者が自分で読み、まとめて直せる必要がある。

## 決定

- 人が読み書きできる行単位のテキストファイル 1 つにする。
- IME は行を末尾に足すだけにし、後に書かれた行が前の行に勝つ。

## 検討した他の案

- 端末ごとの追記ログ（JSON）：同期フォルダでの衝突は避けられるが、人が読んで直すには向かない。
- 端末ごとのテキストファイル：ある端末の登録と別の端末の削除のどちらが勝つかを、時刻なしには決められない。
- SKK の個人辞書の形式：送りありと送りなしで見出しの形が違い、候補を 1 行に並べるので、足すたびに行を書き換える必要がある。
- バイナリの辞書：手で編集できない。

## 結果

- 同期フォルダに置くと、別の端末で同時に書いたときの衝突は同期の仕組みに任せることになる。
- 戻す操作は行を消す必要があるので、設定アプリが行う。
