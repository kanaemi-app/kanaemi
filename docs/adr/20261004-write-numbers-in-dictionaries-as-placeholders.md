# 数を含む語は、辞書に数の置き場所で書く

状態：採用

## 背景

「1個」「二千二十六年」のように、数を含む語は数ごとに辞書に書いていられない。打った数を、語ごとに決まった書き方（半角・全角・漢数字など）で候補にする必要がある。

## 決定

- 辞書の項目の読みと表記に、数の置き場所を書ける。読みの置き場所に打った数が入り、表記の置き場所には、その数を置き場所の書き方で書いたものが入る。
- 置き場所は `{}`、書き方は `{名前}` で書く。文字としての `{` は `\{` と書く。
- 書き方は、SKK の数値変換で広く使われるもの（`#0`〜`#3`・`#5`・`#8`）に当たる分だけ持つ。SKK の辞書を取り込むときは、それぞれ名前に置き換える。
- 確定履歴、よく選ぶ候補、出さないことにした語、辞書登録は、置き場所のままの（読み, 表記）で扱う。

## 検討した他の案

- SKK と同じく `#` で書く：行頭の `#` はコメントなので、`#` で始まる読みが書けなくなる。
- `%` で書く：printf の書式に見え、`%` を含む語と紛れる。
- 数を埋めたあとの（読み, 表記）で記録する：`1こ` で選んだ書き方が、`2こ` に効かない。
- SKK の `#4`（数を辞書で引き直す）と `#9`（将棋の棋譜）も持つ：使う語が少なく、書き方の規則が大きくなる。

## 結果

- `1こ` で選んだ書き方は、ほかの数を打ったときにも効く。
- `#4`・`#9` を使う SKK の辞書の候補は、取り込めない。
- 数を含む読みは、数字から打ち始められる必要がある。
