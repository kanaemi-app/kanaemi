# 数を含む語は、辞書に数の置き場所で書く

状態：採用（書き方の持ち方と、置き場所が必ず数を取ることは `20261006-write-placeholders-as-named-functions.md` で置き換え）

## 背景

「1個」「二千二十六年」のように、数を含む語は数ごとに辞書に書いていられない。打った数を、語ごとに決まった書き方（半角・全角・漢数字など）で候補にする必要がある。

## 決定

- 辞書の項目の読みと表記に、数の置き場所を書ける。読みの置き場所に打った数が入り、表記の置き場所には、その数を置き場所ごとに決めた書き方で書いたものが入る。
- 確定履歴、よく選ぶ候補、出さないことにした語、辞書登録は、数を埋める前の、置き場所のままの語で扱う。

## 検討した他の案

- 数を辞書の外で変換し、語と並べる：「個」「年」のように続く語によって合う書き方が違うのに、語ごとに書き方を決められない。
- 数を埋めたあとの語で記録する：`1こ` で選んだ書き方が、`2こ` に効かない。

## 結果

- 書き方は語ごとに辞書で決まり、`1こ` で選んだ書き方は、ほかの数を打ったときにも効く。
- 数を含む読みは、数字から打ち始められる必要がある。
