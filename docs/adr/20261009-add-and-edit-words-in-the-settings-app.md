# 設定アプリで語を足し、直せるようにする

状態：採用

## 背景

語を登録できるのは、変換中のその場の登録だけだった（`20261003-register-words-inline.md`）。設定アプリは、ユーザーカスタム辞書の語を見る、出さないことにした候補を戻す、登録ごと消すことしかできなかった。

- 読みや語を打ち間違えて登録すると、直すには、出さないことにして登録し直すか、辞書のファイルを手で書き換えるしかない。
- 手で書くと、送り仮名や置き場所の書き方を間違えやすい。間違えた行は無効な行として飛ばされ、書いたその場では分からない。
- 入力中でないときに、まとめて語を足したいこともある。

## 決定

- 設定アプリで、ユーザーカスタム辞書の語を足し、読みと語を直し、消せるようにする。
- 設定アプリで書けるのは、IME の登録で書ける語と同じものに限る。手で書いた、それより多くを持つ行は、設定アプリでは直さない。
- 書く前に、入れた読みと語を確かめる。だめなら書かずに、その場で知らせる。
- 直しても、同じ読みの語の中の並びは変えない。

## 検討した他の案

- 手で書いた行も直せるようにする：IME の登録で書けない語を画面で作れることになり、そのための欄も要る。手で書いた人は、手で直せる。
- 確かめずに書き、無効な行は読むときに飛ばす：手で書くときと同じく、間違えたことが書いたその場で分からない。
- 直すときは、元の語を消して足し直す：同じ読みの語の中で後の語ほど先に出るので、直しただけで並びが変わる。

## 結果

- 設定アプリで足した語は、IME の登録で足した語と同じになる。
- IME の登録で書けない形の行は、設定アプリでは直せない。直すには辞書のファイルを手で書き換える。
- 設定アプリと IME が同じ辞書を書くので、どちらの書き込みも失わないように書く。IME がキーを処理するあいだ待たないことは、`20261009-do-not-wait-on-the-disk-or-a-lock-while-handling-keys.md` による。
