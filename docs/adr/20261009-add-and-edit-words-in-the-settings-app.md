# 設定アプリで語を足し、直せるようにする

状態：採用

## 背景

語を登録できるのは、変換中のその場の登録だけだった（`20261003-register-words-inline.md`）。設定アプリは、ユーザーカスタム辞書（`custom.tsv`）の語を見る、出さないことにした候補を戻す、登録ごと消すことしかできない。

- 読みや語を打ち間違えて登録すると、直すには、出さないことにして登録し直すか、`custom.tsv` を手で書き換えるしかない。
- 手で書くと、送り仮名（`か*く	書く`）や置き場所（`{}こ	{kanji}個`）の書き方を間違えやすい。間違えた行は無効な行として飛ばされ、そのことは辞書の一覧に出るだけで、書いたその場では分からない。
- 入力中でないときに、まとめて語を足したいこともある。

`custom.tsv` は IME も書く。IME は横の `custom.tsv.lock` をほかが持っていると 50 ms までしか待たず、取れなければその行を後回しにする（`20261009-do-not-wait-on-the-disk-or-a-lock-while-handling-keys.md`）。設定アプリの書き直し（戻す、登録ごと消す）は、ロックを持ったまま、新しい中身を一時ファイルに書いてディスクまで書き出し、置き換えていた。macOS ではこの書き出しに数百 ms かかることがあり、そのあいだに登録した語はファイルに書かれずに後回しになる。

## 決定

### 画面

- 設定アプリで辞書の語を見るところで、ユーザーカスタム辞書を開くと、その語の一覧を出す。語を足す、読みと語を直す、消すことができる。同じファイルの語を、見るところと直すところの 2 か所に分けない。
- 読みの欄は、テキストの辞書の読みの書き方に合わせる。送り仮名のある語は送り仮名の前に `*` を入れ（`か*く`）、数は `{}` と書く（`{}こ`）。辞書の語を見る画面も、送り仮名のある語を `か*く` と書いて引く。
- 語の欄は、IME の登録と同じく、置き場所として読める `{…}` を置き場所にする。そう読めない `{` はそのままの文字になる。
- 書けるのは、IME の登録で書ける語、つまり活用型とコストのない語で、送り仮名はかなで書いたものに限る。一覧にも、そのように書き直せる行だけを出す。活用型やコストのある行、送り仮名を行の英字で書いた行（`か*k`）など、手で書いた行は出さず、手で直してもらう。

### 検証

- 書く前に、入れた読みと語を確かめる。だめなら書かずに、そのわけを画面に出す。
  - 読みが空、読みにひらがなと `ー` 以外の文字がある、`*` が 2 つ以上ある、`*` の前が空、`*` の後ろが送り仮名の最初のかな 1 文字でない。
  - 語が空、語にタブや改行などの制御文字がある。
  - 送り仮名のある語で、語がそのかなで終わらない、または置き場所や読みの `{}` がある。
  - 置き場所が読みの `{}` から取る数が足りない、置き場所の関数が組み込みにも functions フォルダにもない。
- 同じ語がもうあれば足さない。直す元の語がもうなければ（手で書き換えたなど）直さない。
- 確かめることと書くことは、UI から分けて engine に置く。画面を動かさずにテストできる。書く行は、テキストの辞書として読み直して同じ語になることも確かめる。

### 書き方

- 足すときは、IME の登録と同じく、末尾に 1 行足す。
- 直すときは、その語の行をその場所で書き換える。同じ語の行がほかにもあれば、最後の行を書き換え、ほかの行は消す。出さない行（`!`）はそのまま残す。
- 消すときは、その語の行をすべて消す。出さない行はそのまま残す。

### ロック

- 足すときは、ロックを持って、ファイルを読んで同じ語がないことを確かめ、1 行足す。ディスクまで書き出すのは、ロックを放してからにする。
- 書き直すとき（直す、消す、戻す、登録ごと消す）は、ロックを持たずにファイルを読み、新しい中身を一時ファイルに書いてディスクまで書き出す。それからロックを取り、ファイルが読んだときから変わっていなければ一時ファイルで置き換える。変わっていれば（そのあいだに IME が行を足したなど）、一時ファイルを消して読み直し、やり直す。3 回やり直しても変わり続けるときは、ロックを持ったまま読んで書く。
- これで、設定アプリがロックを持つのは、ファイルを読み、比べ、置き換えるあいだだけになる。ディスクへの書き出しを待つあいだは、IME はロックを取れる。

## 検討した他の案

- 送り仮名を読みとは別の欄にする：一覧や、辞書の語を見る画面がすでに `か*く` と書いているので、欄だけ書き方が違うと、見たものをそのまま打てない。
- 欄に入れたものを、テキストの辞書の行の書き方（`\{`・`\\` などのエスケープ）で読む：`\` を含む語を `\\` と書く必要があり、IME の登録で書けるものと書き方が違ってしまう。
- 置き場所の関数がなくても書く：IME の登録はそうしているが、ない関数の置き場所は変換しても候補にならない。`{笑}` のように、置き場所のつもりでない `{…}` を書いた語も、黙って置き場所の語になる。設定アプリでは入れたその場で分かるので、書かずに知らせる。
- 直すときに、元の行を消して末尾に足す：同じ読みの語の中で後の行ほど先に出るので、直しただけで順番が変わる。
- 一覧に手で書いた行も出し、直せるようにする：活用型やコストを書く欄が要り、IME の登録で書けない語を画面で作れることになる。手で書いた人は、手で直せる。
- これまでどおり、ロックを持ったまま一時ファイルをディスクまで書き出してから置き換える：そのあいだ IME は 50 ms 待って行を書けず、登録した語が後回しになる。
- 足すときも一時ファイルで丸ごと置き換える：IME と同じ足し方で、読む側が書きかけを見ることはない。置き換えると、ファイル全体を書き出す分だけ遅い。

## 結果

- 設定アプリで足した語は、IME の登録で足した語と同じ行になる。IME は、次に入力欄にフォーカスが入るとき、それを読み直す。
- 手で書いた行（活用型・コスト・行の英字の送り仮名）は一覧に出ない。直すには `custom.tsv` を手で書き換える。
- `{` を文字のまま含み、置き場所としても読める語（`{笑}`）は、設定アプリでも IME の登録でも書けない。
- 足した行は、ロックを放してからディスクに書き出すので、その前に OS が落ちると失うことがある。IME が足す行と同じ扱いになる。
- 書き直しのあいだに IME が何度も行を足すと、一時ファイルを何度か書き出すことになる。そのぶん設定アプリの操作は遅くなるが、IME は待たない。
