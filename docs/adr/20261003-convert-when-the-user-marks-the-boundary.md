# 変換は利用者が区切りを指示した時点で行う

状態：採用

## 背景

ライブ変換はしないので、いつ変換するかを決める必要がある。

## 決定

- 読みを打ち終えて変換を指示したときに変換する。
- 送り仮名の始まりを指定したときは、送り仮名の最初のかなを打った時点で変換し、送り仮名に合う候補だけを出す。

## 検討した他の案

- 送り仮名を指定しても、変換の指示まで待つ：指定した時点で語の区切りは決まっている。漢字＋ひらがなで終わる語を打つ評価では、指定した打ち方の方が第一候補の正解率も高かった（指定しない 91.84%、指定する 93.18%）。
- 送り仮名の指定を必須にする：活用を扱える辞書なら、指定しなくても変換できる。

## 結果

- 辞書には、送り仮名の始まりから引ける索引が要る。
