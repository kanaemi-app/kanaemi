# 変換は、利用者が語の区切りを示したときに行う

状態：採用（送り仮名の最初のかなの後ろに打った文字の扱いは `20261006-convert-again-when-the-okurigana-grows.md` で置き換え）

## 背景

Kanaemi はライブ変換を持たないので、打っている途中のどこで変換するかを決める必要がある。SKK の打ち方では、利用者が読みの区切りと送り仮名の始まりを自分で示す。Kanaemi は、送り仮名の始まりを示さずに読みのまま変換することもできるようにする。

## 決定

- 読みを打ち終えて変換を指示したときに変換する。
- 送り仮名の始まりを示したときは、送り仮名の最初のかなを打った時点で変換し、その送り仮名に合う候補だけを出す。

## 検討した他の案

- 送り仮名の始まりを示しても、変換の指示まで待つ：示した時点で語の区切りは決まっており、もう一度押させる理由がない。漢字とひらがなで終わる語を打つ評価でも、示す打ち方の方が第一候補の正解率が高かった。
- 送り仮名の始まりを示すことを必須にする：活用を扱える辞書なら、示さなくても変換できる。

## 結果

- 辞書は、送り仮名の始まりで区切った読みからも語を引ける必要がある。
- 送り仮名を示さない読みは、変換を指示するまで変換しない。
