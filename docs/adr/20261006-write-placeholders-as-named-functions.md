# 表記の置き場所を、名前で呼ぶ関数で書く

状態：採用（`20261004-write-numbers-in-dictionaries-as-placeholders.md` のうち、書き方の持ち方と、置き場所が必ず数を取ることを置き換える）

## 背景

数の書き方は IME が持つ表から選ぶだけで、利用者は足せない。今日の日付のように、変換するたびに値が決まる語も書けない。SKK は候補に式を書いてこれらを出すが、それでは配られた辞書を入れるだけで、その中のコードが動く。

## 決定

表記の置き場所は、読みの一部か読み全体を、名前で呼ぶ関数で書くことを表す。

- 辞書は、関数の名前と引数だけを持つ。
- 関数は、利用者が Luau で足せる。IME が持つ書き方も、関数の一つとして扱う。
- 関数は、IME が渡す値のほかには触れない。利用者の情報を含む値は、利用者が設定で許したときだけ渡す。
- 関数が止まらなくても、エラーになっても、入力は止めない。

## 検討した他の案

- IME が持つ書き方の表を広げていく：欲しい書き方は人ごとに違い、IME を変えないと足せない。
- SKK と同じく、辞書に式を書いて評価する：辞書を入れるだけでコードが動く。
- 関数に OS の機能を使わせる：拾ってきた関数が、打った文字を外に送れてしまう。

## 結果

- 利用者は、数の書き方や、変換するたびに値が決まる語を、IME を変えずに足せる。
- 置き場所は、数を取らない語の表記にも書ける。
- 辞書の行が出す候補は、利用者が足した関数によって変わる。
