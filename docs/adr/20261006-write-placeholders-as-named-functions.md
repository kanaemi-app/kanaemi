# 表記の置き場所を、名前で呼ぶ関数で書く

状態：採用（`20261004-write-numbers-in-dictionaries-as-placeholders.md` のうち、書き方の持ち方と、置き場所が必ず数を取ることを置き換える）

## 背景

数の書き方は IME が持つ表から選ぶだけで、利用者は足せない。今日の日付や UUID のように、変換するたびに値が決まる語も書けない。SKK は候補に S 式を書いてこれらを出すが、それでは配られた辞書を入れるだけで、その中のコードが動く。

## 決定

- 表記の置き場所は、読みのどの数を（または読み全体を）、どの関数で書くかを表す。読み全体を取る置き場所は、どの語の表記にも書ける。
- 関数は名前で呼び、辞書は名前と引数だけを持つ。関数は利用者が Luau で足せ、IME が持つ書き方もその一つとして扱う。
- 関数は、IME が渡す値のほかには触れない。クリップボードのように利用者の情報を含む値は、利用者が設定で許したときだけ渡す。
- 止まらない、エラーになる関数があっても、入力は止めない。

## 検討した他の案

- IME が持つ書き方の表を広げていく：欲しい書き方は人ごとに違い、IME を変えないと足せない。
- SKK と同じく、辞書に式を書いて評価する：辞書を入れるだけでコードが動く。
- 関数に OS の機能を使わせる：拾ってきた関数が、打った文字を外に送れてしまう。

## 結果

- 利用者は、数の書き方や変換するたびに値が決まる語を、IME を変えずに足せる。
- 辞書の行が出す候補は、利用者が足した関数によって変わる。
