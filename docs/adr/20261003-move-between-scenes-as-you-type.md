# 場面の移り方を打ち方で決める

状態：採用

## 背景

かなモードには、何も打っていない、読みを打っている、候補を選んでいる、語を登録しているといった場面がある。どの操作でどの場面に移るか、とくに読みと送り仮名の始まりをどう示すかを決める必要がある。

## 決定

- かなモードで打ったかなは、その場で確定する。変換する語だけを読みとして打つ。
- 読みの始まりと送り仮名の始まりは、利用者が「始める」機能で示す。機能はほかの機能と同じく、場面ごとにキーへ割り当てる。何も打っていないときは読みを、読みを打っているときは送り仮名を始め、候補を選んでいるときは選んでいる候補を確定して次の読みを始める。
- 読みを始めた直後、まだ何も打っていないうちにもう一度「始める」と、読みをやめ、そのキーの文字を打つ。
- 候補を選んでいる間に文字を打つと、選んでいる候補を確定してから、その文字を打つ。
- 取り消す操作は、1 つ前の場面に戻る。
- モードを切り替えたときや、入力欄からフォーカスが外れたときは、見えているものを確定してから移る。

## 検討した他の案

- 打ったかなをすべて未確定に溜め、まとめて変換する：変換しない語まで変換の対象になり、区切りを自分で決める打ち方と合わない。
- SKK のように、大文字で読みと送り仮名の始まりを示す：Shift を押す必要があり、数字や記号から読みを始められない。かなモードで大文字そのものも打てなくなる。
- Shift の代わりになるキー（Sticky Shift）で大文字を打たせて示す：Shift の意味が変わり、記号はキー配列によって変わる。数字から読みを始められないことも変わらない。
- 候補を確定するには、確定の操作を必須にする：続けて打つたびに、1 つ余分に押す必要がある。
- モードを切り替えたときに、打っている途中のものを捨てる：打った内容が、気づかないうちに失われる。

## 結果

- 読みにしない語は、変換の操作なしで打てる。
- 数字や記号からも読みを始められる。
- 「始める」に割り当てたキーは、そのキーの文字を打つのに 2 回押す必要がある。
- 文字のキーは、候補を選んでいる間は確定の操作も兼ねる。
