# モードの表示を IME が自分で出す

状態：採用

## 背景

Shift の単独押しでモードが変わるので、切り替えた瞬間にどちらのモードかを知らせる必要がある。

## 決定

- 入力ソースは 1 つだけにし、OS の入力モードの仕組みは使わない。
- モードが変わったことは、IME が自分でカーソルの近くに表示する。

## 検討した他の案

- OS の入力モードの仕組みを使う：OS ごとに仕組みと表示が違う。OS 側でもモードを切り替えられるようになり、IME の中のモードと同期させる必要がある。

## 結果

- 表示に使う窓とカーソル位置の取り方は、OS ごとの入力方式が持つ。
