# モードは OS の入力モードの仕組みに載せず、IME が自分で示す

状態：採用

## 背景

モードはキーの単独押しで変わる（`20261003-keep-two-modes-and-treat-the-rest-as-scenes.md`）。気づかないうちに切り替わることがあるので、切り替えた瞬間にどちらのモードかを知らせる必要がある。

## 決定

OS には入力ソースを 1 つだけ見せ、モードは OS の入力モードの仕組みに載せない。モードが変わったことは、IME が自分で示す。

## 検討した他の案

- OS の入力モードの仕組みを使う：OS ごとに仕組みと表示が違う。OS の側からもモードを切り替えられるようになり、IME の中のモードと揃え続ける必要がある。

## 結果

- モードを切り替えるのは IME だけになり、OS の側と揃える必要がない。
- モードの示し方は、OS ごとの入力方式がそれぞれ作る。
