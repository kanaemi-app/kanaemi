# 判断はすべて、I/O を持たない core の状態機械に置く

状態：採用

## 背景

IME の枠組みは OS ごとに違う。一方で、キーの意味も変換の結果も、どの OS でも同じにしたい。

## 決定

- 入力の判断はすべて core に置く。core は I/O を持たない同期の状態機械で、イベントを受けて、表示すべき状態の全体と、確定する文字列と、キーをアプリに渡すかを返す。時刻もイベントとして受け取る。
- OS ごとの入力方式は、OS のイベントと core のイベントの変換と、core の出力の描画だけを持つ。
- 辞書の読み書きは core の外が持つ。
- core の中でエラーが起きても入力を止めない。OS ごとの入力方式が core を作り直し、キーをアプリに渡す。

## 検討した他の案

- OS ごとに判断を書く：OS の数だけ振る舞いがずれる。
- 出力を前回との差分で返す：OS ごとの入力方式が前回の状態を覚える必要があり、ずれたときに戻せない。

## 結果

- core の振る舞いは、イベント列と出力列の組でテストできる。OS ごとの入力方式のテストは、イベントの変換と描画に絞れる。
- 新しい OS に対応するときに、判断を書き直す必要がない。
