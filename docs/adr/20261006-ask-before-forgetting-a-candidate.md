# 候補を出さなくする前に、もう一度押して確かめる

状態：採用

## 背景

候補を以後出さなくする機能は、押した瞬間に効いていた。押し間違えても確かめず、取り消しもない。戻すには設定アプリを開き、出さないことにした語の一覧から探す必要がある。

IME は、変換の途中にダイアログを出せない。出せたとしても、文字を打つ流れが止まる。未確定文字列とその印は、どの環境でも必ず見える（`20261003-show-preedit-markers-as-text.md`）。

## 決定

候補を出さなくする機能は、1 度目は確かめるだけにし、続けてもう一度押したときに出さなくする。

- 確かめていることは、未確定文字列の中に、もう一度押すと何が起きるかを文で添えて伝える。
- 確かめている間にほかの操作をしたら、確かめるのをやめる。

## 検討した他の案

- 押したあとで取り消せるようにする：IME はユーザーカスタム辞書に行を足すことしかしない（`20261003-keep-the-user-custom-dictionary-as-editable-text.md`）。出さないとした記録を行を足して打ち消すと、ほかの辞書の語が、自分で登録した語に変わってしまう。
- 既定で、押し間違えにくいキーに割り当てる：押しにくくなるだけで、押し間違えたときに確かめられないのは変わらない。
- 確かめる画面を出す：変換の途中には出せる場所がなく、出せても打つ流れが止まる。

## 結果

- 出さなくするには、2 度押す必要がある。
- 確かめている間は、未確定文字列が添えた文の分だけ長くなる。
