# 辞書登録をその場で行う

状態：採用

## 背景

候補に出したい語がないときに、入力を止めずに辞書に足せるようにしたい。

## 決定

- 候補を回りきったら、その読みの語を登録する場面に入る。
- 登録する語は、ふだんと同じ打ち方で打つ。変換も、その中でのさらに登録もできる。
- 確定すると、語を書き込める辞書に登録し、その語を確定する。

## 検討した他の案

- 設定アプリで登録する：入力の流れが途切れ、登録してから打ち直す必要がある。
- 候補を回りきったら、最初の候補に戻るだけにする：候補にない語を打つ手段がなくなる。

## 結果

- 登録の中の登録を扱う必要があり、入れ子の深さには上限を設ける。
- 登録した語は、その場で次からの候補に出る。
