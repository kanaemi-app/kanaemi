# 組み込みの関数を使う辞書を、組み込みの辞書として本体に入れる

状態：採用（`20261003-dictionaries-as-an-ordered-list.md` のうち、辞書を本体と別に配ることを、組み込みの関数で値が決まる語について置き換える）

## 背景

辞書を本体と別に配るのは、変換の語彙を、資料を解析して作り、変換の正解率で確かめる必要があるからである。「きょう」を今日の日付にするような語は、組み込みの関数を呼ぶ行を手で書くだけでできる。語を選ぶ解析も、正解率での確かめも要らない。

## 決定

- 組み込みの関数で値が決まる語の辞書は、組み込みの辞書として本体に入れる。変換の語彙は入れず、これまでどおり本体と別に配る。
- 組み込みの辞書は複数あり、名前で区別する。ほかの辞書と同じく、辞書の一覧に並べて優先度を決め、外せる。一覧を書かなければ、最後にすべて使う。

## 検討した他の案

- 公式の辞書（kanaemi-dict）の追加辞書として配る：解析と評価のための仕組みに、それを要らない辞書を載せることになる。
- 組み込みの辞書を 1 つにまとめる：一部の語だけを使う、外すということができない。
- 組み込みの辞書を既定で一覧の先頭に置く：利用者や公式の辞書の同じ読みの語より、組み込みの語が先に並ぶ。

## 結果

- 組み込みの辞書は、本体と同じ版で出て、呼ぶ組み込みの関数と揃う。
- 組み込みの辞書は、ほかの辞書と同じく `!` の行で語を出さなくできる。
