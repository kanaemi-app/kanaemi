# 辞書を並び順のある一覧として扱う

状態：採用（辞書の入手は `20261006-install-official-dictionaries-from-the-settings-app.md` で置き換え）

## 背景

使う辞書には、配られている辞書、SKK の辞書を変換したもの、利用者が登録した語がある。

## 決定

- 辞書に種類の区別はない。並べた順がそのまま優先度になる。
- 書き込める辞書（ユーザーカスタム辞書）は 1 つだけで、常に一覧にある。辞書登録と、ほかの辞書の語を出さないという記録はここに書く。
- 辞書は利用者が入手して一覧に足す。IME 自身は辞書を取りに行かない。辞書は Kanaemi の本体とは別に配る。

## 検討した他の案

- システム辞書とユーザー辞書を分ける：種類ごとに扱いの規則が分かれる。
- 辞書を本体に同梱する：辞書と本体で、更新の周期もライセンスも違う。

## 結果

- どの辞書からも候補が得られなくても、辞書登録はできる。
