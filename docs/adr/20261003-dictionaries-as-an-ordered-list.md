# 辞書を種類で分けず、並び順のある一覧として扱う

状態：採用（辞書の入手は `20261006-install-official-dictionaries-from-the-settings-app.md` で置き換え）

## 背景

使う辞書には、配られている辞書、SKK の辞書を変換したもの、利用者が登録した語がある。出どころはさまざまだが、どれも読みから候補を引くことに変わりはない。

## 決定

- 辞書に種類の区別を設けず、一覧に並べた順をそのまま優先度にする。
- 書き込める辞書（ユーザーカスタム辞書）は 1 つだけにし、常に一覧に置く。辞書登録と、ほかの辞書の語を出さないという記録は、ここに書く。
- 辞書は Kanaemi の本体とは別に配り、利用者が入手して一覧に足す。IME 自身は辞書を取りに行かない。

## 検討した他の案

- システム辞書とユーザー辞書のように種類を分ける：種類ごとに扱いの規則が分かれ、どちらが勝つかを種類ごとに決める必要がある。
- 辞書を本体に同梱する：辞書と本体では、更新の周期もライセンスも違う。

## 結果

- 優先度を変えるには、一覧の順を入れ替えればよい。
- どの辞書からも候補が得られなくても、辞書登録はできる。
