# 未確定文字列の場面を、装飾ではなく文字の印で示す

状態：採用

## 背景

未確定文字列では、読みを打っている、候補を選んでいる、語を登録しているといった場面と、送り仮名の始まりを見分ける必要がある。下線などの装飾は、端末のように描けない環境がある。そうした環境では、フォントによって文字の幅も変わる。

## 決定

場面と送り仮名の始まりは、未確定文字列の中に文字の印として出し、装飾には頼らない。印には、フォントによって幅が変わりにくい文字を使う。

## 検討した他の案

- 装飾で表す：装飾を描けない環境で場面が見えない。

## 結果

- 装飾を描けない環境でも、どの場面かが見える。
- アプリから見える未確定文字列には印の文字が入り、打った内容より長くなる。
